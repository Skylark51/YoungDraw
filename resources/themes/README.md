# YoungDraw 작업실 배경

상단 **배경 · 테마** 또는 **보기 → 배경 · 테마…**에서 선택합니다.

- 아틀리에: 네이비와 샴페인 골드, 밝은 작업면
- 미드나이트: 블루와 민트, 어두운 작업면
- 아카이브: 아이보리 연구 노트
- 백룸: 노란 다마스크 벽지, 형광등, 끝없는 Level 0
- 노스텔지아: 여름비가 그친 창가, CRT와 카세트, 노을
- 공포: 폐실험실, 냉랭한 청록빛과 붉은 경고등

문양은 없음·도트·격자·줄노트·등각 격자·육각 결합, 배경 강도는 세 단계입니다. 선택 즉시 미리보며 취소하면 이전 설정으로 돌아갑니다. 적용한 설정은 현재 사용자의 `HKCU\Software\YoungDraw\Appearance`에 저장합니다.

배경 이미지는 실행 파일의 RCDATA 201–203에 포함되므로 실행 파일 하나로 동작합니다. 전체 배경과 문양을 합성한 결과를 화면 크기별로 캐시합니다. 구조의 검정·회색과 어두운 색상은 어두운 테마에서 화면 표시만 밝게 조정합니다. 문서, SVG, CDXML, Office 출력에는 배경과 화면용 색상 변환이 포함되지 않습니다.

JPEG 배경은 내장 image_gen 도구로 생성한 원본을 JPEG로 변환했습니다. 생성 프롬프트는 `prompts.txt`에 보관합니다.
