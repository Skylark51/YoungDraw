점선 단일 결합은 왼쪽 **점선 단일 결합** 도구 또는 **삽입 → 점선 단일 결합**에서 사용합니다. 선택한 결합들을 한 번에 변환하거나 기존 결합을 클릭하고, 드래그하여 새 점선 결합을 그릴 수 있습니다. 단일 결합 도구로 클릭하거나 결합 위에서 `1`을 누르면 실선으로 되돌립니다. `.ydraw`·CDXML 저장 및 SVG·Office 복사에도 점선 표시가 유지됩니다.

첫 구조 없는 메커니즘은 **삽입 → 첫 구조 없이 분기 메커니즘** 또는 오른쪽 **첫 구조 없이 분기**에서 생성합니다. 각 분기의 마지막 구조마다 가로·아래 **+**가 표시되며 누른 구조에서 다음 단계가 이어집니다. 가져온 메커니즘 정리는 기본으로 **원본 구조 위치·묶음 유지**를 사용합니다. 간격을 새로 맞출 때는 정리 창의 **간격 자동 재배치**를 선택합니다.

# 세로선 분기와 가져온 반응 상태 정리

- **삽입 → 세로선 분기 화살표**(오른쪽 메커니즘 탭과 우클릭 메뉴에도 표시): 공통 세로선에 2~20개 가로 화살표를 만듭니다. 기존 세로 직선을 선택하면 그 선을 재사용합니다. 분기 수·세로선 높이·가로 길이·좌우 방향을 미리보기로 조정하며 생성된 묶음은 함께 이동합니다. Ctrl+Shift+G로 풀어 개별 편집하고 Ctrl+Z로 되돌립니다.
- **가져온 메커니즘 정리**: 화살표로 구분되는 같은 영역의 여러 분자·이온을 하나의 반응 상태 칸으로 묶습니다. 분자 사이의 `+`도 유지합니다. 서로 멀리 떨어진 하나의 상태는 먼저 Ctrl+G로 묶어 지정할 수 있습니다. 공통 세로선에서 시작하는 외부 분기는 가짜 반응물 구조를 만들지 않으며, 단계 표에서 시작 구조 **0**으로 표시됩니다.
- 정리 미리보기에서 **원본 좌표 유지 / 2D 결합 각도·길이 정돈**, 구조 묶음의 **회전·배율·좌우/상하 반전**을 선택합니다. 정리 후 구조 삽입 영역을 선택하고 Ctrl+Shift+K로 모양을, Ctrl+K로 크기를 다시 조절합니다. 이미지 자체의 결합은 재작성하지 않습니다.
- `CoIII`, `LCoIII`, `FeII` 등의 산화수는 정리 중 위첨자로 바꿉니다. 가져온 CDXML의 글자별 색상·글꼴을 유지하고 여러 텍스트 run에 나뉜 로마 숫자도 인식합니다. 기존 캡션 글자 크기도 유지합니다.

## 구조 정리의 가지 겹침 개선

- **구조 정리 (Ctrl+Shift+K)**에서 배치 뒤 겹침이 남으면 단일 결합을 축으로 가지 방향을 바꿔 해결을 시도합니다. 라벨과 결합선의 겹침을 함께 검사하며 결합 길이와 분자의 중심 위치를 유지합니다.
- RDKit의 결합 뒤집기 코드를 YoungDraw 모델에 맞게 재작성했습니다. 기존 단일 실행 파일에서 작동하며 **보기 → 오픈소스 라이선스**에서 출처 고지를 확인할 수 있습니다.
- 보호·입체·배위 구조와 기준 템플릿에는 기존 보존 정책을 적용합니다. 자세한 구현 범위는 [구조 정리 개발 문서](docs/structure-cleanup.md)를 참고하세요.

## 메커니즘 편집과 ChemDraw 서식

- **현재 파일 → 메커니즘 편집**은 별도 창에서 변환 결과를 보여줍니다. 원본 보기로 비교하고, 단계·연결·이름·에너지·배치를 편집한 뒤 적용합니다. 취소하면 원래 문서가 유지되며 적용은 한 번의 실행 취소로 되돌릴 수 있습니다.
- **메커니즘 편집**에서 그림 영역 아래 **+**는 분기, 끝의 **+**는 다음 단계, 화살표 옆 **+**는 중간체 삽입입니다. 첫 단계와 중간 단계에서도 분기할 수 있습니다. 영역·화살표 선택 후 **Delete**, **Ctrl+Z / Ctrl+Y**, 더블클릭 이름·에너지 편집을 지원합니다. **이름·에너지 표**로 기존 표 편집도 사용할 수 있습니다.
- **연결하기**에서 시작 영역과 도착 영역을 클릭하거나 드래그합니다. 그림 영역 드래그로 배치하고, 길이 슬라이더로 화살표 길이를 조절합니다. 배치 선택은 직선·세로·여러 줄·촉매 순환·분기·합류를 지원합니다.
- 기본 에너지 단위는 **kcal mol⁻¹**입니다. 단위 선택은 표시만 바꾸며 값을 자동 환산하지 않습니다. 추가 설정에서 여백·글자 크기·자동 화살표 길이를 조절할 수 있습니다.
- 사이드바의 단계 추가·삭제 버튼을 정리하고 **단계 편집표 → 메커니즘 편집**, **크기·간격 → 자동 정렬**, **삽입 칸 → 그림 영역**으로 바꿨습니다. 작은 그림 영역에서도 안내 글자가 밖으로 나오지 않도록 잘라 표시합니다.
- **예제 열기**는 네 가지 경로와 조작 안내가 담긴 편집 가능한 도움말을 새 탭에 엽니다. CDXML로 저장할 수 있습니다.
- **구조 정리**에서 선택 부분만 정리하거나 연결된 분자 전체를 정리할 수 있습니다. 부분 정리는 나머지 원자와 연결 경계를 고정합니다.
- CDXML의 메커니즘 연결은 편집 가능한 표준 화살표·곡선으로 저장합니다. 확대된 구조의 원자 라벨 크기·굵기와 결합선 굵기를 노드·분자 조각에 함께 명시하여 ChemDraw의 자동 라벨 서식을 맞춥니다.

## 프로젝트 관리

- 프로젝트 관리 도구는 아이콘으로 표시하며 마우스를 올리면 기능 이름이 나타납니다. 영역 사이 경계를 드래그해 프로젝트 목록과 미리보기 너비를 조절하면 다음 실행에도 유지됩니다. 작은 창에서는 도구 모음이 여러 줄로 배치됩니다.
- **Ctrl+F**로 현재 프로젝트의 파일명·폴더명·노트를 검색합니다. 검색 결과에 마우스를 올리면 전체 이름과 소속 폴더를 확인할 수 있습니다.
- **새 폴더** 아이콘으로 하위 폴더를 만들고 더블클릭으로 들어갑니다. **상위 폴더** 아이콘 또는 목록에서 Backspace로 돌아옵니다. 원본 파일 연결은 그대로 유지됩니다.
- Ctrl·Shift로 여러 항목을 선택하고 폴더 위에 드래그하거나 **선택 항목 이동**을 사용합니다. 검색 중에는 폴더 이동을 지원하며 순서 변경은 검색을 해제한 뒤 사용합니다. 탐색기의 파일 여러 개를 목록이나 폴더 위에 끌어놓아 추가할 수 있습니다.
- 파일은 더블클릭 또는 Enter로 열고, 우클릭 메뉴에서 이름·노트 편집(F2), 복제, 이동, 선택 항목 ZIP 내보내기, 원본 위치 열기, 목록에서 제외(Delete)를 실행합니다. 폴더를 제외하면 하위 항목도 함께 목록에서 제외되며 파일은 복구를 위해 보관됩니다.
- **미리보기 확대** 아이콘이나 미리보기 더블클릭으로 큰 화면을 전환합니다. 확대·축소·배율 초기화 아이콘과 미리보기 위 마우스 휠을 지원합니다.
- 노트는 입력 후 자동 저장되고 **저장 중… / 저장됨 / 저장 실패** 상태를 표시합니다. 항목 전환과 창 닫기 전에도 저장합니다.
- 기존 프로젝트를 그대로 읽을 수 있습니다. 저장 시 폴더 정보를 지원하는 프로젝트 형식(v2)을 사용하므로 수정한 프로젝트는 최신 YoungDraw로 여세요. ZIP 내보내기·불러오기도 폴더 분류를 유지합니다.


## 구조 정리, 직접 배치, GIF 중간 프레임

- **템플릿 → 2D 배치 기준 / 작용기**에서 고리 그림과 R이 붙은 작용기 구조를 찾아 삽입합니다. **Ctrl+Shift+K**의 권장 모드는 일치하는 고리에 기준 그림을 맞추고, 그 외 구조에는 일반 2D 정리를 사용합니다. 적용 전후를 같은 배율로 비교할 수 있습니다.
- **편집 → 선택 구조의 작용기 약어**에서 일치하는 작용기를 확인하고 한 종류 또는 전체를 축약합니다. Ph, Boc, TMS, OAc, CF₃ 등 17종을 지원합니다. 방금 적용한 축약은 Ctrl+Z로 되돌릴 수 있습니다.
- **편집 → 선택 원자의 Mulliken 스핀 값**에서 계산 결과를 값 열에 붙여넣거나 직접 입력합니다. 입력한 값은 해당 원자 위에 표시되며 빈칸으로 지울 수 있습니다. 구조 칸에 든 분자는 독립 편집 창에서도 같은 메뉴를 쓸 수 있습니다.
- **선택 도구**로 그래프 준위를 위아래로 끌면 에너지가 바뀝니다. Shift는 축 눈금에 맞추고, Alt를 누른 채 끌면 모든 경로에서 해당 상태의 가로 위치가 바뀝니다. 직선·분기 메커니즘은 삽입 칸을 표시하고 Alt+드래그로 각 단계와 구조를 함께 옮길 수 있습니다.
- **결합 애니메이션 GIF → 중간 프레임 설계**에서 구간과 원자 위치를 골라 새 중간 구조를 만듭니다. 독립 창에서 원자 위치, 결합 형성·분해, 스핀 값을 편집하고 적용합니다. 재생 설정에서 대응 원자에 양쪽 값이 있을 때 숫자가 연속으로 변하도록 설정할 수 있습니다. 편집 중인 타임라인은 GIF 미리보기 창에서 관리합니다.

## 단계 구조 독립 편집·화살표 비례

- **병렬 경로 자동 정렬**: 길이가 다른 경로와 중간 분기의 기존 행을 유지하면서 열과 간격을 맞춥니다. 새 분기에는 이어지는 단계들까지 같은 행을 배정하며, 순환·되돌아오는 연결을 긴 한 줄로 펼치지 않습니다. 여러 단계를 함께 그룹으로 묶어도 각 단계에 속한 구조만 측정·이동합니다. 반복 정렬·저장 후 다시 정렬해도 행이 합쳐지거나 구조가 밀리지 않습니다.

- **단계 삽입 / 단계 제거**: 오른쪽 **단계·연결** 또는 **배치 / 우클릭** 메뉴에서 원하는 위치에 단계를 넣고 뺍니다. 최대 40단계를 지원합니다. 제거 시 기본값은 구조를 캔버스에 유지하고 단계·연결만 제거하는 방식이며, 구조까지 삭제할 수도 있습니다. 선택한 구조 칸에서 Delete를 눌러도 단계 제거 창을 엽니다.
- **단계 합치기**: 하나의 구조가 두 단계로 인식되었으면 제거할 단계와 구조를 받을 단계를 지정합니다. 원자·결합을 유지하고 연결 번호를 다시 맞추며 자기 자신으로 향하는 연결과 중복 연결을 제거합니다.
- **드래그 연결**: 메커니즘을 선택하고 **드래그 연결**을 누른 뒤 시작 구조 칸에서 도착 구조 칸까지 끕니다. 여러 도착 단계에 반복해서 연결할 수 있습니다. Esc로 연결 모드를 끝내고 **크기·간격 자동 정렬**을 누르면 연결 관계에 따라 열·분기를 다시 배치합니다. 화살표가 없는 상태도 그대로 저장됩니다.
- 연결선을 클릭하면 양끝에 원형 조절점이 나타납니다. 조절점을 다른 단계에 놓으면 시작·도착을 바꿉니다. 화살촉을 빈 곳에 가로로 끌면 길이를 조정합니다. **화살표 길이**에서 pt 단위로 입력할 수도 있으며 0은 자동입니다. 메커니즘의 화살표들은 같은 길이 기준을 공유합니다. 연결선을 선택하고 Delete 또는 **선택한 연결 제거**로 삭제합니다.
- **연결 표 편집**은 구조·화살표 행의 추가·삭제를 지원합니다. 구조 번호는 기존 항목의 식별 번호이며 새 구조에는 새 번호를 입력하거나 비워 둘 수 있습니다. 새 화살표의 번호는 비워 두고 시작·도착 구조 번호를 지정합니다. 삭제된 단계의 구조는 캔버스에 유지됩니다. 모든 변경은 Ctrl+Z로 되돌리고 `.ydraw`·CDXML에 저장할 수 있습니다.
- 인식된 `CoIII`·`FeII` 등의 산화수 로마 숫자는 일반 글자 크기의 **55%**인 위첨자로 표시합니다. 가져온 글자별 색상과 글꼴을 유지하며 이미 위첨자로 표시된 산화수도 같은 비율을 적용합니다.

- 메커니즘이나 그래프의 구조 영역을 선택하고 오른쪽 **구조 고치기 · 독립 창**, 우클릭 메뉴의 같은 항목 또는 **편집 → 구조 고치기 · 독립 창**을 누릅니다. 구조 영역을 더블클릭해도 열립니다. 해당 단계의 원자·결합·텍스트·이미지만 별도 YoungDraw 창에 표시됩니다.
- 독립 창에서 **적용 / Ctrl+S**를 누르면 선택한 단계의 구조만 교체합니다. 다른 단계의 구조·이름·에너지·배치는 유지합니다. **취소 / Ctrl+W / 창 닫기**는 원본을 변경하지 않습니다. 적용한 수정은 원래 문서에서 Ctrl+Z 한 번으로 되돌립니다. 빈 구조 영역에서도 새로 그릴 수 있습니다.
- 자동 배치의 화살표 길이는 실제 글꼴로 측정한 가장 긴 설명·TS 이름·화살표 에너지의 너비에 작은 여백을 더해 맞춥니다. 구조 아래의 단계 이름은 화살표 길이를 늘리지 않습니다. 분기의 추가 가로 여백도 줄였습니다. 기존 문서는 **크기·간격 자동 정렬**을 누르면 새 간격을 적용합니다.
- 가져온 구조의 중심 높이에 작은 차이가 있어도 같은 줄의 연결 화살표는 수평 직선으로 표시합니다. 구조의 원래 위치는 유지하며, 다른 줄로 이어지는 실제 분기의 세로 연결은 유지합니다. 기존 문서에도 다시 열면 적용됩니다.
- 화살표가 길어지면 선과 화살촉도 함께 굵어집니다. **구조 크기 조정 / Ctrl+K**는 좌표와 함께 결합선 굵기, 원자 라벨·전하, 텍스트·도형 선 굵기를 조정하며 `.ydraw`·CDXML 저장에 유지합니다.

## 내 프로젝트

실행하면 기존처럼 편집 화면으로 바로 진입합니다. 상단 맨 왼쪽 폴더 아이콘 **내 프로젝트** 또는 **파일 → 내 프로젝트**에서 프로젝트를 생성·선택·삭제합니다. 프로젝트 **정보**에서 이름과 전체 노트를 수정합니다.

- **새 구조**는 프로젝트 안에 편집 문서를 만들고 바로 엽니다. **현재 문서 추가**는 현재 작업의 복사본을 보관합니다.
- **파일 추가** 또는 탐색기에서 파일을 끌어 넣어 `.ydraw`, `.cdxml`, PNG, JPEG, GIF를 함께 보관합니다. 원본 파일을 복사하므로 외부 원본을 이동해도 프로젝트가 유지됩니다.
- 항목을 선택하면 미리보기와 파일 노트가 표시됩니다. 노트는 **노트 저장**, 항목·프로젝트 전환 및 창을 닫을 때 저장합니다. **이름·노트** 또는 F2로 표시 이름을 변경합니다.
- **열기 / 편집** 또는 더블클릭하면 YoungDraw 탭에서 수정할 수 있습니다. Ctrl+S는 프로젝트 안의 문서에 저장합니다. CDXML도 동일하게 관리하며, 기존 CDXML 가져오기·보존 범위가 적용됩니다.
- 이미지는 YoungDraw 캔버스에서 이동·크기 조정·구조 추가 등을 할 수 있습니다. Ctrl+S는 원본 옆의 별도 `.ydraw` 편집 문서에 저장하며, 다시 열면 수정본을 불러옵니다. 이미지 원본은 유지합니다.
- 항목을 위아래로 **드래그**하면 삽입 위치가 표시되며 순서가 저장됩니다. 목록 가장자리에서는 자동 스크롤하며, **위로 / 아래로** 버튼도 제공합니다.
- 저장 위치는 `%LOCALAPPDATA%/YoungDraw/Projects`입니다. 프로젝트 삭제 시 열린 문서의 저장 여부를 확인하고 `%LOCALAPPDATA%/YoungDraw/ProjectTrash`로 옮깁니다. 항목 삭제는 목록에서만 제거하고 내부 파일은 복구를 위해 보관합니다.
- **이전 프로젝트 불러오기**: 내 프로젝트의 **불러오기**에서 이전 프로젝트 폴더 안의 `project.ydproject`를 선택합니다. 구조·이미지·이미지 편집본·이름·노트·순서를 이 PC의 프로젝트 보관함에 복사하며 원본은 유지합니다. 파일이 빠진 프로젝트는 누락 안내를 표시합니다.
- **PC 사이 이동**: 연구실 PC에서 **내 프로젝트 → 내보내기**로 USB·공유 폴더에 복사합니다. 열려 있는 해당 프로젝트 문서의 수정 내용도 저장합니다. 생성된 **폴더 전체**를 집 PC로 옮긴 뒤 **불러오기**를 사용하세요. `project.ydproject` 하나나 실행 파일만 복사하면 내부 문서를 가져올 수 없습니다. 자동 동기화는 제공하지 않습니다. **폴더** 버튼으로 선택한 프로젝트의 저장 위치를 엽니다.

Windows 화학 구조·반응 메커니즘·에너지 그래프 편집기입니다. C++17, Win32/GDI+, XmlLite를 사용하며 별도 GUI 런타임 설치가 필요하지 않습니다.

- **에너지 그래프 양쪽 분기**: 그래프를 선택하고 오른쪽 **그래프 → 양쪽 분기 추가** 또는 **배치 → 그래프 양쪽 분기 추가**를 누릅니다. 첫 상태를 중앙의 공통 반응물로 두고 기존 경로를 오른쪽에 유지하며, 선택한 경로를 왼쪽으로 복제합니다. **데이터 표 편집**에서 양쪽 상태 이름과 에너지를 각각 수정하며 빈칸은 해당 경로에서 제외됩니다. 복제한 구조 삽입 칸은 비워 두고 기존 구조는 오른쪽에 유지합니다. 미리보기·취소·Ctrl+Z, .ydraw/CDXML 저장 및 SVG·Office 출력을 지원합니다. 원본 상태는 2~50개까지 가능합니다.

- **메커니즘 가독성·확장**: 설명·이름·에너지의 자동 글자 크기를 확대하고 가장 긴 표시 텍스트에 맞춰 모든 직선 화살표 길이를 통일했습니다. 불필요한 가로 여백을 줄이며 자동 줄바꿈 없이 직접 입력한 줄바꿈을 유지합니다. 기존 문서는 메커니즘 선택 후 **크기·간격 자동 정렬**로 새 간격을 적용합니다.
- **원형 + 버튼·세로 배치**: 선택 도구에서 메커니즘 마지막 구조 옆의 원형 **+**를 누르면 TS와 다음 구조 칸이 추가됩니다. **메커니즘 설정 → 배치 → 세로 한 줄 (위에서 아래)**를 선택하면 아래쪽으로 확장됩니다. 세로 화살표 왼쪽에 설명, 오른쪽에 TS 이름·에너지를 표시합니다. 버튼은 SVG·Office 출력에서 제외되며 추가는 Ctrl+Z로 되돌릴 수 있습니다.
- **메커니즘 이름 첨자**: 이름 편집 표의 **x₂ / x²** 버튼 또는 **Ctrl+= / Ctrl+Shift+=**를 사용합니다. `I_{1}`, `TS^{+}` 표기도 지원하며 화면·SVG·CDXML·Office에 반영됩니다.

## 메커니즘 편집 추가 기능

- **벤젠 → Ph**: 고리 또는 벤젠이 포함된 그룹 선택 → 우클릭 **벤젠을 Ph로 축약**, 또는 **Ctrl+Shift+P**. 단일 결합 하나로 연결된 비치환 페닐 고리만 축약하며, 연결 원자와 결합은 유지합니다. 다중 치환·융합 고리는 제외합니다.
- **CDXML 메커니즘 정리**: CDXML을 연 뒤 정리할 구조·반응 화살표·텍스트를 함께 선택하고 **배치 → 가져온 메커니즘 정리 (구조 보존)**를 실행합니다. 선택이 없으면 문서의 자유 구조들을 대상으로 합니다. 분자 내부 좌표·결합·입체표현·전하를 유지한 채 구조 칸을 옮기며, 직선 반응 화살표의 시작·끝으로 분기 연결을 추정합니다. 가까운 이름·설명·에너지를 각 프레임에 배치하고 `/`로 구분한 에너지를 S=0/1/2 순서로 표시합니다. `?`, `?.?`, `*` 표시도 유지합니다. 가까운 독립 원자 표기(예: +H⁺)와 전자 이동 곡선은 함께 보존합니다. 정리 후 **선택 항목 편집**에서 구조 번호와 연결·텍스트를 검토하고 수정할 수 있습니다. 가져오기 자체에는 기존 결합 길이 자동 보정을 적용하지 않습니다.
- **반응 화살표 중앙 X**: 화살표를 선택하고 우클릭 **화살표 중앙 X 설정**. 메커니즘 전체를 선택한 경우 화살표 번호를 지정합니다. 표시/숨김, 굵기, 크기, 색상을 조절하며 미리보기·취소를 지원합니다. 자유 화살표와 가로·세로·꺾인·순환 메커니즘 화살표에 적용됩니다.
- **분기 추가**: 가로 메커니즘 선택 → 우클릭 **메커니즘 분기 추가** → 시작 구조 번호 입력. 아래쪽 경로에 빈 구조 칸을 만들고 연결선을 표시합니다. **선택 항목 편집**에서 구조 이름·에너지와 화살표의 시작/도착 구조 번호·설명을 편집합니다. 분기 메커니즘은 가로 프레임 배치를 유지합니다.
- **전하 중복 방지**: 명시적 원자 라벨에 이미 있는 +/− 위첨자를 같은 원자의 형식 전하로 중복 표시하지 않습니다. 라벨에 없는 명시적 형식 전하는 계속 표시합니다. 문서의 전하 데이터는 유지합니다.

위 기능은 Ctrl+Z, .ydraw/CDXML 저장·재열기와 SVG·Office 벡터 출력에 반영됩니다. CDXML의 구조·텍스트 연결은 위치에 따른 추정이므로 결과를 편집 표에서 검토하세요. 원본의 미지원 도형은 기존 CDXML 보존 정책을 따릅니다.

## 실행

**이 폴더의 `YoungDraw.exe`를 실행하세요.** 빌드 산출물과 검증 그림은 `build/`에 보관합니다. 템플릿 저장 위치는 기존과 같은 `%LOCALAPPDATA%/YoungDraw/Templates`입니다. 문서는 저장 대화상자에서 지정한 위치에 저장됩니다.

실행하면 앱 아이콘이 있는 시작 화면이 약 1.2초 표시되고, 아래로 살짝 이동하며 사라진 뒤 편집 창으로 이어집니다. Windows에서 애니메이션을 끈 경우에는 바로 전환합니다. Office 내장 편집과 명령행 변환·테스트에서는 시작 화면을 표시하지 않습니다.

Visual Studio 2022 C++ Build Tools와 CMake가 있는 개발 환경에서는 다음과 같이 빌드합니다. 테스트가 통과하면 루트 폴더에 실행 파일을 복사합니다.

```powershell
./build.ps1
./YoungDraw.exe
./YoungDraw.exe examples/v03-coordinate.ydraw
```

## 이번 버전의 변경

- **첫 실행 기본 테마**: 테마 설정이 없는 PC에서는 밝은 아이보리 계열의 아카이브로 시작합니다. 기존에 저장한 테마 선택은 유지합니다.

- **버튼 글꼴·정렬 검수**: 테마 카드와 문양·배경 강도·확인 버튼의 글자를 키우고 가로·세로 가운데로 맞췄습니다. 한글 UI 글꼴과 텍스트 렌더링을 통일하고, 좁은 도구 버튼은 글자 공간을 확보했습니다. 테마·템플릿·문서 탭의 화면 버퍼를 픽셀 크기 그대로 출력해 Windows 배율에 따른 축소와 위치 어긋남을 방지합니다.

- **그룹 만들기 (Ctrl+G)**: 선택 도구에서 Shift+클릭 또는 드래그로 구조·화살표·텍스트·이미지를 여러 개 선택한 뒤 Ctrl+G로 묶습니다. 그룹 안의 객체를 클릭하면 전체가 선택되어 함께 이동·복사·삭제됩니다. 그룹 텍스트는 더블클릭하거나 텍스트 도구로 편집합니다. **Ctrl+Shift+G**로 그룹을 해제하며, 편집 메뉴에서도 실행할 수 있습니다. 그룹은 .ydraw/CDXML 저장과 실행 취소·다시 실행에 유지됩니다.

- **상단 메뉴·아이콘 도구 모음**: 맨 위에 한글 메뉴(파일·편집·삽입·배치·보기)를 두고 그 아래에 아이콘 도구 모음을 한 줄로 배치했습니다. 문서·실행 취소/다시 실행·화면/배치·템플릿·회전/반전을 구분선으로 묶고, 아이콘에 마우스를 올리면 한글 기능 설명을 표시합니다.

- **벤젠·ChemDraw 단축키·배위 템플릿 개선**: 벤젠을 75%로 줄이고 2D 정리에서도 벤젠–바깥 탄소 연결 85%를 유지합니다. ChemDraw 방식의 객체 정렬·간격 배분, 회전·반전·이동 단축키를 추가했습니다. **다시 실행: Ctrl+Shift+Z / 작업 반복: Ctrl+Y**. [단축키 대조표](docs/chemdraw-shortcuts.md), [peroxo 및 M–NO/nitrite 템플릿](docs/lab-templates.md)을 참고하세요.

- **결합 길이·도구 모음·오비탈 개선**: C/N/O의 결합 차수별 길이, 작업별 오른쪽 도구 탭, 상단 버튼 정렬, 왼쪽 오비탈 도구를 추가했습니다. 사용법과 길이 기준은 [개선 안내](docs/drawing-tools.md)를 참고하세요.

- **화면 배율에 따른 작업 영역 축소 수정**: Windows 배율이 다른 PC에서 작업 영역이 창의 일부에만 그려지고 문서 탭·버튼 위치가 어긋나는 문제를 수정했습니다. DPI 설정을 초기화 전에 적용하고 화면 버퍼를 픽셀 크기 그대로 복사합니다.

- **단계 설명 가독성·화살표 비례 조정**: 단계·화살표 표의 **글자 크기 (pt, 0: 자동)**에서 단계별로 4~72 pt를 지정합니다. 0이면 상태 이름과 같은 크기를 사용하며, 긴 설명은 줄바꿈하여 다른 단계까지 작아지는 문제를 방지합니다. 화살표 선 두께와 화살촉도 해당 글자 크기에 비례해 조정하며, 여러 줄 텍스트의 가운데 높이에 배치합니다. 범위가 극히 좁아 글자 한 개도 들어가지 않을 때만 크기를 제한합니다.

- **메커니즘 ㄹ자 배치**: 메커니즘 선택 → **메커니즘 설정** → 배치에서 **ㄹ자 (아래로 이어 그리기)**를 선택합니다. 한 줄의 구조 수(TS 제외, 기본 3개)와 줄 사이 최소 여백을 지정하면 오른쪽→아래→왼쪽→아래 순서로 이어집니다. 줄 끝 연결선은 구조와 이름·에너지를 피해 바깥쪽으로 돌며, 정방향·평형 화살표, 미리보기·취소·실행 취소, .ydraw/CDXML 저장 및 SVG·Office 출력에 반영됩니다. 구조가 크거나 이름이 여러 줄이면 줄 간격을 자동으로 확보합니다.

- **그래프 메커니즘 단계·화살표**: 그래프를 선택한 뒤 오른쪽 **그래프** 탭 → **반응 이름·화살표** 또는 배치 → **반응 이름·화살표**에서 단계 이름과 시작·끝 위치(가로 축 전체의 0~100%)를 표로 편집합니다. x축 위에 `← Reactant →`처럼 텍스트 양옆으로 화살표를 표시합니다. 새 그래프의 기본값은 Reactant / Transition State / Product이며, 단계 추가·삭제, 겹치는 범위의 줄 분리, 캔버스 이름 직접 편집, 미리보기·취소·실행 취소를 지원합니다. 모든 행을 삭제하면 표시를 숨깁니다. 기존 문서는 그대로 열리고 이 편집창에서 기본 단계를 추가할 수 있습니다. .ydraw/CDXML 저장과 SVG·Office 출력에도 반영됩니다.

- **구조 크기 조정 (Ctrl+K)**: 원자·결합 또는 이미지를 선택하고 Ctrl+K를 누르면 배율(1~1000%)로 크기를 조정합니다. 원자·결합을 일부 선택해도 연결된 분자 전체를 같은 비율로 확대·축소합니다. 구조 삽입 영역을 선택한 경우에는 그 영역의 구조를 대상으로 하며 필요한 삽입 공간과 이웃 구조 위치도 조정합니다. 입력 중 미리보기를 제공하고 취소 시 복원하며 Ctrl+Z로 되돌릴 수 있습니다. 100%는 현재 크기 유지이며 Ctrl+Shift+K 구조 정리는 기존과 같습니다. 편집 메뉴에서도 실행할 수 있습니다.
- **클립보드 구조 삽입**: 구조를 Ctrl+C로 복사한 뒤 메커니즘 또는 그래프의 구조 삽입 영역을 클릭하고 Ctrl+V를 누르면 해당 영역에 파일 삽입과 같은 크기·가운데 정렬 기준으로 붙입니다. 삽입 영역을 선택하지 않은 상태에서는 일반 캔버스 붙여넣기를 유지합니다. YoungDraw 구조, CDXML 클립보드 데이터, XML 텍스트를 읽으며 원자와 결합은 편집 가능한 상태로 유지합니다. 삽입은 Ctrl+Z로 되돌릴 수 있습니다.
- **여러 문서 탭**: 도구 모음 아래의 탭으로 열린 파일을 전환합니다. 새 문서와 열기는 기존 문서를 유지하고 새 탭을 만들며, 열기 창에서 여러 파일을 한 번에 선택할 수 있습니다. 문서별 저장 경로·수정 표시·실행 취소/다시 실행·확대/이동·선택 영역을 따로 유지합니다. Ctrl+Tab / Ctrl+Shift+Tab으로 전환하고 탭의 × 또는 Ctrl+W로 닫습니다. 수정한 문서는 닫을 때 저장 여부를 확인하며 앱 종료 시 모든 탭을 확인합니다. 명령행에 여러 파일을 지정해도 각각 탭으로 엽니다.
- **단계별 메커니즘 편집**: 표는 `구분 / 이름·설명 / S / 에너지`의 4열입니다. 행은 `중간체 → TS → 중간체` 순서로 배치합니다. 단계마다 S를 `0 / 2`, 에너지를 `0.0 / 13.4`처럼 같은 순서로 입력하면 S 순서에 맞게 함께 정렬합니다. 각 중간체와 TS에 서로 다른 S 조합을 지정할 수 있습니다. 중간체 에너지는 가로·순환 배치 모두 구조 이름 아래에, TS 에너지는 해당 화살표 아래에 표시합니다. TS 이름 칸에 `TS1 / 산화 반응`처럼 입력하면 `TS1`은 에너지 바로 위에, `산화 반응`은 화살표 위에 따로 표시하며 각각 직접 편집할 수 있습니다. 슬래시 없이 저장된 기존 설명의 위치는 유지합니다. S=0은 검정, S=1은 빨강, S=2는 파랑입니다. 그 외 정수·반정수 S는 회색과 명시적 S 표기로 구분합니다. 단계 추가·삭제·복제는 중간체와 연결 TS를 함께 처리합니다. 마지막 셀에서 Enter·Tab을 눌러도 다음 단계는 자동으로 생성하지 않으며 적용 버튼으로 이동합니다. 선택한 S에 값이 아직 없어도 보관하며 빈칸·마지막 행·입력 중인 셀도 적용합니다. 오류가 있으면 입력과 기존 문서를 유지하고 문제가 있는 행을 표시합니다. .ydraw/CDXML 재열기와 SVG·Office 출력에도 단계·에너지·색을 유지합니다.
- **버튼식 템플릿 갤러리**: 상단의 리간드·배위 착물·기질·산·시약 버튼에서 그림 목록을 바로 엽니다. 그림을 클릭하면 오른쪽에 크게 미리 보이며 이름 검색과 분류 버튼, 페이지 이동을 지원합니다. 금속을 미리 바꾸어 본 뒤 삽입 버튼·더블클릭·Enter로 삽입합니다. 닫기·Esc는 문서를 변경하지 않습니다.
- **선택 구조 회전·반전**: 상단 버튼 또는 편집 메뉴에서 좌우 반전, 상하 반전, 반시계/시계 90°, 각도 지정 회전을 실행합니다. 원자나 결합을 고르면 해당 분자 전체를 회전하여 결합이 찢어지지 않습니다. 선택한 그룹의 텍스트·화살표도 함께 이동하며 글자는 똑바로 유지합니다. 임의 각도는 +가 시계방향, −가 반시계방향입니다. Ctrl+Z / Ctrl+Shift+Z로 되돌리기·다시 실행할 수 있습니다.


- **텍스트 깜빡임 수정·가운데 정렬**: 입력 중 문서와 전체 화면을 매번 갱신하지 않고 확정할 때만 반영합니다. 편집 상자는 공간이 부족할 때만 확장합니다. 새 텍스트와 여러 줄은 중심점을 유지해 가운데 정렬합니다.
- **실험실 템플릿 152개 내장**: 오른쪽 템플릿에서 리간드 7종, axial/equatorial 배위 표현과 peroxo·hydroperoxo 조합, 원본 MPDAP 착물, 기질 12종, HOTf 등 산·시약 6종을 고릅니다. Youngcraft 자료와 지정한 AfterPhD CDXML을 참조했습니다. 출처·표현 가정·검증은 [실험실 템플릿 안내](docs/lab-templates.md)에 있습니다.
- **입체 투영 보호**: 보호 속성·금속·배위결합·쐐기·해시·회색 뒤쪽 표시가 있는 성분은 구조 정리에서 좌표를 바꾸지 않습니다. 뒤쪽 표시는 편집 메뉴에서 선택 부분을 회색/검정으로 조정할 수 있으며 저장·내보내기에 유지됩니다.


- 공명 결합 도구를 왼쪽 그리기 영역의 이중결합 옆으로 옮겼습니다. Space/x/j/e/t/l/r/a 단축키는 각 아이콘 바로 아래의 같은 높이에 13 px 굵은 글씨와 밝은 파란색 띠로 표시합니다.

- **공명·비편재화 결합 (실선+파선)**: 결합 또는 탄소 세 개를 선택하고 왼쪽 그리기 영역의 **공명 결합 (실선+파선)** 버튼이나 삽입 메뉴, `a`를 누르면 선택한 결합들을 한 번에 변환합니다. 선택이 없으면 이 도구로 직접 그리거나 기존 결합을 클릭합니다. 실선은 구조 골격에 유지하고 부분 이중결합의 파선을 고리 또는 연결된 공명 영역의 안쪽에 표시합니다. 같은 결합을 다시 클릭하면 파선 위치를 반대로 바꿉니다. 다른 결합 도구나 결합 위 `1`/`2`로 일반 결합으로 되돌릴 수 있습니다. .ydraw에 종류·방향을 보관하며 CDXML에는 1.5차 결합, SVG에는 실선·파선으로 내보냅니다. `r`은 별도의 양방향 화살표입니다.

- **텍스트 직접 편집 개선**: 입력 상자를 글자 크기에 맞추고 편집 중 큰 선택 테두리를 숨깁니다. Enter/바깥 클릭: 확정, Shift+Enter: 줄바꿈, Tab/Shift+Tab: 다음/이전 텍스트, Esc: 취소. 선택한 객체의 텍스트를 클릭하거나 텍스트를 더블클릭하면 바로 편집하며, 그래프·가로 메커니즘의 텍스트도 같은 방식으로 수정합니다. 객체의 글꼴·색·굵기를 편집 상자에 반영합니다.
- **구조 정리 개선**: 일반 사슬은 동일한 결합 길이와 120° 지그재그로, 삼중결합·연속 이중결합의 중심은 180°로 배치합니다. 단순 고리·공유 변을 가진 융합 고리는 정다각형으로 배치하고 분기의 겹침을 피하는 방향을 선택합니다. 원자뿐 아니라 결합·그룹·반응 블록을 선택해도 해당 분자를 정리합니다. 쐐기·해시·보호된 의자형 및 금속 배위 투영은 좌표를 그대로 보존합니다. 복잡한 가교 고리·배위 구조 전체를 처리하는 범용 화학 배치 엔진은 아닙니다.
- **결합 그리기 보정**: 기존 원자에서 결합을 뻗으면 120° 또는 삼중결합 주변 180° 방향을 제안합니다. 원자에 연결하면 그 위치를 우선하며 Alt+드래그는 자유 배치입니다.
- **공명 화살표**: 삽입 → 공명 화살표 또는 빈 공간에서 `r`을 눌러 ↔ 화살표를 그립니다. Shift+드래그: 수평·수직. 화살촉 속성에서도 공명(양쪽 화살촉)을 선택할 수 있습니다.

## 화살표와 기능 설명

사이드바와 도구 모음의 버튼에 마우스를 약 0.45초 올려두면 기능 설명과 관련 조작법이 표시됩니다.

반응 화살표·전자쌍 이동 화살표·단전자 이동 화살표는 드래그하는 동안 완성 모양의 곡선과 화살촉을 미리 보여 줍니다. 전체 화살촉은 선이 화살촉 밑에서 끝납니다. 단전자 이동의 반쪽 화살촉은 곡선 끝까지 이어지는 선에 같은 굵기의 갈고리 한쪽을 붙이며, 갈고리는 끝의 접선 방향에 맞춰 곡선 바깥쪽에 놓입니다. 화면·SVG·CDXML에 같은 모양으로 표시됩니다.

원자 또는 결합선에서 원자·결합선으로 화살표를 그리면 전자 이동 곡선으로 처리합니다. 결합선은 클릭한 위치에 연결되며 이중·삼중결합의 바깥 선과도 여백을 둡니다. 자동 곡선의 굽힘은 원자 사이 거리에 맞춰 작게 제한하여 위로 과도하게 솟지 않도록 했습니다. 원자 라벨(수소·전하 포함)과 화살표 양끝 사이에 여백을 두고, 주변 원자를 피하도록 곡선의 방향·크기를 선택합니다. 연결한 원자나 결합의 원자를 움직이면 화살표도 다시 배치합니다. 화살표만 복사하거나 이동하면 현재 모양을 유지하며 연결을 해제합니다. **곡선 직접 수정**: Space로 선택 도구를 켜고 화살표를 클릭하면 양끝의 빈 원 2개와 곡률 조절점 2개가 표시됩니다. 점을 드래그하면 양끝 위치나 곡선 모양을 바꿉니다. 직접 수정한 곡선은 원자·결합 연결을 해제하고 현재 모양으로 고정하며 저장 후에도 유지됩니다. Esc로 수정 취소, Ctrl+Z / Ctrl+Shift+Z로 되돌리기·다시 실행이 가능합니다. 속성창의 곡률은 `자동` 또는 숫자로 지정할 수 있으며, 숫자를 직접 지정하면 현재 위치에서 수동 곡선으로 바꿉니다.

## 메커니즘 배치

구조를 삽입하거나 단계·문구를 수정하면 구조 크기와 설명·에너지의 폭을 함께 계산하여 단계 간격을 맞춥니다. 메커니즘의 가장 긴 설명·이름·에너지에 여백을 더한 길이를 모든 화살표에 공통으로 적용합니다. 화살표 위 설명과 하단 이름·에너지는 같은 자동 글자 크기를 사용하며, 긴 설명은 화살표와 단계 간격을 늘려 수용합니다. 직접 입력한 줄바꿈은 유지합니다. 큰 구조에는 글자와 화살촉·선 굵기도 비례해 키웁니다. 기존 문서는 **자동 크기·간격 정렬**로 새 배치를 적용합니다.

**Ctrl+Shift+K**는 구조 정리 미리보기를 엽니다. 기본 **원본 형태·방향 유지 / 기준 크기 맞춤**은 상대적인 결합 각도와 투영 형태를 유지하며 결합 길이의 중앙값으로 크기를 맞춥니다. **2D 결합·고리 재정리**는 평면 구조를 다시 정리하며 인식된 금속·입체·보호 구조는 유지합니다. 추가 회전 각도로 원하는 방향을 미리 확인하고 적용합니다. 구조 삽입 영역을 선택하면 해당 칸의 구조만 처리합니다. 취소는 원본을 복원하고 적용 후에는 Ctrl+Z로 되돌립니다.

일반 텍스트, 원자 라벨, 메커니즘의 이름·설명, 그래프 제목·상태 이름과 텍스트 속성창에서 **Ctrl+=**는 아래첨자, **Ctrl+Shift+=**는 위첨자입니다. 글자를 선택하면 그 부분에 적용하고 선택이 없으면 첨자 입력을 시작합니다. 같은 키를 다시 누르면 일반 입력으로 돌아갑니다. `H_{2}`, `Fe^{III}` 형식으로 저장하며 화면·SVG·CDXML에서도 작은 글자와 위·아래 위치를 반영합니다.

선택 도구에서 마지막 반응 단계의 옆과 아래에 **+** 버튼이 표시됩니다. 아래 **+**를 누르면 그 위치에서 다음 줄로 내려가고, 옆 **+**는 첫 줄에서 오른쪽, 둘째 줄에서 왼쪽, 셋째 줄에서 다시 오른쪽으로 단계를 추가합니다. 각 줄의 길이를 자유롭게 정해 지그재그로 이어갈 수 있으며, 저장·다시 열기와 실행 취소에서도 배치를 유지합니다.

단계 추가 후 전체 메커니즘이 보이도록 화면을 자동으로 맞춥니다. 5개를 넘는 단계도 추가할 수 있으며, 표에서 단계를 늘려 적용한 뒤에도 전체 배치를 표시합니다. 에너지 칸의 미정 값은 `?` 또는 `?.?`로 입력합니다. 여러 스핀 값은 `12.5 / ?.? / ?`처럼 `/`로 구분하며, 미정 표시는 그림·저장·다시 열기에서 그대로 유지됩니다.

**자동 크기·간격 정렬**을 누르면 선택한 반응 블록의 구조·이름·화살표 간격을 다시 맞춥니다. 선택이 없으면 기존 반응 블록 전체를 처리합니다.

직접 그린 구조들도 선택한 뒤 정렬할 수 있습니다. 기존 반응 블록이 선택되지 않은 경우, 분자 연결 성분과 이미지들을 단계로 만들고 가까운 텍스트를 함께 연결합니다. 분자는 원래 형태를 유지한 채 결합 길이를 통일하고, 기존 자유 반응 화살표는 단계 사이 연결로 바꿉니다. 단계 순서는 현재 왼쪽에서 오른쪽 순서입니다. 원하는 객체만 선택해서 실행하는 것을 권장합니다. 결과는 Ctrl+Z로 되돌릴 수 있습니다.

**촉매 순환 배치**는 마지막 단계에서 첫 단계로 돌아가는 곡선 화살표를 포함한 원형 메커니즘을 만듭니다. **메커니즘 설정**에서 가로·순환 배치와 정방향·평형 화살표, 단위를 바꿀 수 있습니다. 순환의 단계 이름·에너지·화살표 설명·가운데 텍스트는 캔버스에서 직접 편집합니다. 단계 추가·삭제와 가로 배치의 설명은 표에서도 편집할 수 있습니다.

구조를 복사한 후 `+ 구조 삽입` 영역을 클릭하고 **구조 붙여넣기**를 누르세요. **구조 파일 삽입**으로 CDXML/.ydraw 파일도 넣을 수 있습니다. 삽입 영역 안내선은 내보내지 않습니다.

ChemDraw에서 구조를 선택하고 **Ctrl+C**, YoungDraw에서 **Ctrl+V**로 붙여넣습니다. ChemDraw의 바이너리 클립보드 형식(`ChemDraw Interchange Format`)을 직접 읽어 원자·결합·라벨·일반 텍스트를 편집 가능한 객체로 가져옵니다. 메커니즘이나 그래프의 구조 삽입 영역을 먼저 선택하면 해당 칸에 들어가며, **구조 붙여넣기** 버튼도 같은 형식을 지원합니다. 좌표·원소·전하·동위원소·결합 방향과 텍스트의 글꼴·색·스타일을 읽습니다. 바이너리 데이터가 손상되었으면 오류를 표시합니다. 바이너리의 도형·이미지 등 나머지 객체는 아직 가져오기 범위에 포함하지 않습니다.

## 저장·내보내기

- **애니메이션 GIF 삽입**: 탐색기에서 GIF 파일을 복사하고 메커니즘의 삽입 칸을 선택한 뒤 **Ctrl+V** 또는 **구조 붙여넣기**를 누릅니다. **구조 파일 삽입**에서도 GIF/PNG/JPEG 파일을 선택할 수 있고, 왼쪽 **이미지 삽입** 도구로 캔버스에 직접 넣을 수 있습니다. GIF 원본이 제공되는 클립보드 형식(`GIF`, `image/gif`)도 지원합니다. 프레임별 재생 시간·투명도·반복 설정을 유지하며, 이동·크기 조정과 저장 후 다시 열기에도 원본 애니메이션을 보존합니다. 이미지당 최대 10 MB입니다. 브라우저가 정지 비트맵만 복사하는 경우에는 GIF 원본 파일을 저장한 뒤 삽입하세요.
- **GIF 내보내기**: `.ydraw`와 `.cdxml`에 GIF 원본 전체를 보관하고 SVG에는 `image/gif`로 포함합니다. SVG에서의 재생은 보는 프로그램의 GIF 지원에 따릅니다. PNG 미리보기와 Office의 EMF 그림은 첫 프레임을 사용하며, Office 편집 원본에는 GIF를 보관하므로 YoungDraw에서 다시 편집할 때 재생됩니다.

- **Ctrl+S**: ChemDraw와 YoungDraw에서 열 수 있는 `.cdxml` 문서 저장. 블록·순환 배치·그래프·축 설정·구조 연결·이미지 원본을 보관합니다.
- **CDXML**: 일반 원자·결합·텍스트·곡선·그림으로 내보냅니다. 편집용 YoungDraw 정보도 annotation으로 보관합니다. ChemDraw에서 보이는 객체를 수정했다면 외부 수정이 우선합니다.
- **SVG**: pt 단위 벡터 그림. 축의 회전·첨자·색과 범례 배치를 반영합니다.
- 예전 `.ydraw` 문서는 계속 열 수 있습니다. 패치의 전역 변환은 접근 가능한 로컬 고정 드라이브를 검색해 CDXML을 만들고 원본을 `.ydraw.bak`으로 보관합니다. 이름이 충돌하는 파일과 변환 오류는 결과 기록에 남습니다. 가져온 CDXML의 미지원 객체는 원본 XML로 보존하지만 화면과 SVG에서 모두 표시하지는 못할 수 있습니다.
- `.cdx` 파일 직접 열기, MOL/RXN/SMILES는 지원하지 않습니다. ChemDraw의 Ctrl+C 바이너리 클립보드는 위 구조 가져오기 범위에서 지원합니다. 새 회전·순환 표시의 실제 ChemDraw 왕복은 별도 확인이 필요합니다.

## 이미지·그래프 레이어 잠금

오른쪽 **레이어** 탭(또는 보기 → 레이어 패널)에서 이미지와 그래프를 따로 잠글 수 있습니다. **이미지만 편집**을 누르면 그래프가 잠겨, 겹치는 그래프의 제목·축·구조 삽입 영역이 눌리지 않습니다. **그래프만 편집**은 이미지를 잠그고, **모두 잠금 해제**는 양쪽을 다시 편집할 수 있게 합니다. 각 행의 **잠김 / 편집 가능** 버튼으로 개별 레이어를 전환할 수도 있습니다.

잠긴 항목은 그대로 표시되지만 클릭·더블 클릭·드래그·박스 선택·Ctrl+A에서 제외되며 이동·삭제되지 않습니다. 이미지와 그래프는 종류별로 자동 분류되고, 잠금은 문서별로 저장되며 Ctrl+Z로 되돌릴 수 있습니다. 일반 원자·결합·텍스트 편집은 계속 가능합니다.

전하·라디칼은 결합선과 라벨을 피해 자동 배치합니다. **Space로 선택 도구를 켠 뒤 표시 자체를 드래그**하면 원자를 움직이지 않고 표시 위치를 바꿀 수 있습니다. 옮긴 위치는 저장되며 Ctrl+Z로 되돌릴 수 있습니다. 원자 라벨과 일반 텍스트에서 `CoIII`, `FeII`, `MnIV`처럼 입력하면 로마 숫자 산화수를 자동으로 위첨자 처리합니다.

원자 위 n/o/c/C/b/B/s/S는 N/O/C/Cl/Br/B/S/Si로 바꿉니다. 결합 위 1/2/3은 결합 차수를, w/h/d/b/y는 쐐기/해시/점선/굵은선/물결선을 바꿉니다. 모든 ChemDraw 단축키를 구현한 것은 아닙니다.

### 부분 크기 조정과 벤젠 기본 크기

원자·결합의 일부를 선택한 뒤 **Ctrl+K**를 누르면 선택한 부분만 지정 배율로 조정합니다. 선택한 결합의 양 끝 원자는 함께 조정되며, 선택하지 않은 연결 원자나 그룹의 나머지 부분은 움직이지 않습니다. 선택 부분과 나머지를 잇는 결합은 이동한 원자 위치를 따라갑니다. 배율의 기준점은 선택 부분의 중심입니다.

새 벤젠 고리의 기본 결합 길이는 일반 결합 길이의 **80%**입니다. 빈 공간에 만들거나 원자에 붙일 때 적용되며, 기존 결합에 융합하는 고리는 공유 결합 길이를 유지합니다. 이전 버전 문서를 열 때도 벤젠과 벤질 탄소 연결 길이를 새 기준으로 한 번 갱신합니다. 저장 후에는 사용자가 조정한 크기를 다시 초기화하지 않습니다. 자동 갱신은 Ctrl+Z로 되돌릴 수 있습니다.

구조 정리의 기본 방식은 2D 고리·결합 재정리입니다. 벤젠은 일반 결합의 80%, 벤젠–벤질 탄소 연결은 85%를 유지합니다. 산화수 라벨은 실제 글자 영역만큼 결합선을 잘라내며, 라벨이 있는 고리는 모든 고리 결합에 가시 길이가 확보될 때까지 모양을 유지해 확대합니다. 단순 5각 킬레이트는 금속 원자가 있어도 정리할 수 있고, 탄소의 네 결합을 직각 십자로 벌리는 배치는 피합니다. 명시적으로 보호한 구조와 입체·복잡한 배위 구조의 투영은 유지합니다.


### 그래프의 화살표 배치와 구간 색상

- 그래프를 선택한 뒤 오른쪽 **그래프 → 화살표 자석 배치**에서 새 반응 이름 또는 기존 이름을 선택합니다. 준위에 나타난 왼쪽 끝·중앙·오른쪽 끝의 두 점을 차례로 클릭하면 양쪽 화살표의 범위가 맞춰집니다. 점에 가까이 가면 강조되며, Esc로 취소할 수 있습니다. 기존 퍼센트 표 편집도 사용할 수 있습니다.
- **그래프 → 구간별 색상**에서 경로와 시작·끝 준위를 선택합니다. 준위·표식, 사이 연결선 또는 둘 모두에 색상을 적용할 수 있어 하나의 경로 안에 여러 spin 구간을 표현할 수 있습니다. 미리보기, 취소, 기본 색상 복원 및 Ctrl+Z를 지원하며 저장·CDXML·SVG에도 반영됩니다.
- 일반 그래프·새 경로와 **양쪽 분기 추가**로 만든 좌우 경로의 연결선은 기본 파선입니다. 평평한 준위는 실선으로 유지되며 경로 스타일에서 연결선 종류를 변경할 수 있습니다.

상단 **원자 색상표** 오른쪽의 **텍스트 색상표 (A)**로 단계 텍스트의 색을 바꿉니다. 단계 이름·설명을 더블클릭해 편집하는 중에 팔레트를 누르면 해당 문구에만 적용하고, 반응 블록을 선택한 뒤 누르면 블록의 텍스트 전체에 적용합니다. 일반 텍스트도 지원하며, 실행 취소·다시 실행 및 .ydraw/CDXML 저장·SVG/Office 출력에 색을 유지합니다. 회전 도구의 아이콘과 도움말은 시계/반시계 방향에 맞춰 표시됩니다.

탄소 원자 위에서 소문자 `c`를 누르면 결합된 탄소도 원소기호 `C`를 명시적으로 표시합니다. 표시는 저장 후에도 유지되며 Ctrl+Z로 되돌릴 수 있습니다. 대문자 `C`는 기존대로 염소(Cl) 단축키입니다.


## 그래프 편집 개선 (2026-11-12)

- 새 그래프의 에너지 단위는 **kcal mol⁻¹**입니다.
- **그래프·축 설정 → 축 표시**에서 y축 눈금과 숫자를 함께 숨기거나, 세로 제목 대신 축 위에 **E**를 표시할 수 있습니다. E 배치에서도 에너지 단위를 표시합니다.
- **그래프·축 설정 → 범례 위치**의 X/Y 이동값(pt)으로 범례를 옮깁니다. 오른쪽과 아래쪽이 양수입니다.
- 에너지 표에서 마우스로 셀 범위를 드래그한 뒤 **Delete**로 값을 한꺼번에 지웁니다. **행 삭제**는 선택 범위의 행을 삭제합니다.
- 표의 **되돌리기 / 다시 실행** 버튼 또는 **Ctrl+Z / Ctrl+Shift+Z**로 값 수정·붙여넣기·행 추가/삭제를 복원합니다.
- 이름·축 제목 편집 중 **Ctrl+=**는 아래첨자, **Ctrl+Shift+=**는 위첨자입니다. **F9 / F10**도 사용할 수 있습니다.
- 새 다중도 비교 그래프의 상태 이름은 이탤릭 **S = 0 / S = 1 / S = 2**입니다.

- **축 표시**에서 x축과 y축을 각각 숨길 수 있습니다. 숨긴 축의 선·눈금·제목은 출력에서도 제외되며, 데이터와 상태 이름은 유지됩니다. 상단 E와 단위는 y축 화살촉 위 한 줄에 표시합니다.


## 메커니즘 그림 편집 (2026-11-13)

- 편집창 상단 아이콘의 **그림 그리기 / 붙여넣기 / 파일 넣기**로 선택한 그림 영역에 구조를 넣습니다. 영역을 더블클릭해도 독립 구조 편집기가 열립니다. 구조 편집기의 **적용하고 돌아가기**로 반영하고, 메커니즘 창의 **적용**으로 원본에 저장합니다.
- 촉매 순환의 그림 영역 옆 **+**는 순환을 유지하며 다음 중간체를 추가합니다. 직선형의 영역 아래 **+**는 해당 중간체에서 분기합니다. 추가 창에서 분기점·새 단계·TS의 이름과 에너지를 함께 입력합니다.
- TS 위에는 분기용 +를 표시하지 않습니다. TS 화살표를 선택하면 **중간체 삽입**으로 해당 연결에 단계를 넣을 수 있습니다. **F2 / 이름·에너지**로 선택 항목의 문구를 수정합니다.
- 아이콘 도구는 창 너비에 따라 여러 줄로 배치됩니다. 선택이나 배치에 맞지 않는 도구는 비활성화됩니다. **원본 비교**, **화면 맞춤**, **확대/축소**, **되돌리기/다시 실행**을 지원합니다.


### 원형 경로와 연결별 설정

- 화살표를 클릭한 뒤 **연결 N · 화살표 모양**에서 그 연결만 정방향/평형으로 바꿉니다. 다른 화살표는 유지되며 .ydraw와 CDXML에 저장됩니다.
- **원형 · 마지막 연결 없음** 배치를 선택하거나 **마지막 → 처음 연결**을 끄면 열린 원형 경로가 됩니다. 마지막 화살표와 해당 TS 설명을 함께 숨기며 다시 켤 수 있습니다.
- 촉매 순환의 그림 영역을 선택하고 **분기 추가**를 누르면 순환 바깥에 새 경로를 만듭니다. 순환 본체의 곡선, 개별 평형 설정, 분기점·새 단계·TS의 이름과 에너지를 유지합니다.
- 편집 도구는 **구조 입력 / 단계·연결**, **배치·설정 / 보기 / 편집 기록**의 두 줄로 정리됩니다. 다크 테마에서도 버튼 모서리를 배경색으로 채웁니다.
