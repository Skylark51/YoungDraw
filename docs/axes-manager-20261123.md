# X·Y축 관리 통합

그래프 관리 → 축·글자에서 X축 관리와 Y축 관리를 하나의 **축 관리** 카드로 합쳤다. 카드는 기존 X축 카드 위치에 있으며 다른 카드 위치는 유지한다.

한 편집 화면 안의 7개 아이콘으로 X 축선·제목·상태 이름, Y 축선·제목·범위와 눈금·단위를 바로 선택한다. 중간 축 선택 화면을 추가하지 않는다. 두 축의 입력값과 미리보기를 함께 유지하며 적용·취소·실행 취소를 한 번에 처리한다. 기존 X축·Y축 개별 명령도 유지한다.

이미 X축 편집 중인 상태에서 Y축의 세부 항목으로 이동하는 경로는 기존 적용/취소 → Y축 카드 → 세부 탭(3클릭)에서 해당 아이콘 1클릭으로 줄어든다. 기본 축선 항목은 기존 2클릭에서 1클릭이다. 이는 동일한 시작 조건의 UI 경로 비교이며 사용자 작업 시간 측정은 아니다.

`plot_axes_manager`는 격리 데스크톱의 실제 편집창에서 900×640 및 1280×900 요청 크기를 검사한다. 7개 아이콘을 실제 클릭하고, 탭 및 보이는 입력란이 부모 영역 안에 있는지 확인한다. 양축 동시 미리보기, 입력값 유지, 적용·취소·실행 취소·다시 실행, 잘못된 값의 적용 차단을 검사한다. 원래 `graph_manager`의 개별 축 명령 검사도 유지한다.

검증 로그와 전체 크기별 캡처는 `build/axes-unified`에 보관한다. 요청 크기와 실제 DPI 배율은 구별하며, 이 검사는 물리적 고배율 화면 검증을 대신하지 않는다.

통합 후 ΔE·ΔG 선택을 세로·상단 배치에서 각각 검사했다. 선택하면 축 제목 입력란·미리보기·SVG가 함께 갱신된다. 기존 그래프·축 설정의 같은 선택 경로도 검사한다. 로컬 최종 전체 CTest 33/33(58.09초), 실제 실행 파일의 20개 내보내기 검사가 통과했다.
