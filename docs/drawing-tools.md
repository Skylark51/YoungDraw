# 결합 길이와 도구 모음 개선

## 결합 길이

새로 그리는 C/N/O 결합은 결합 차수별 공유 반지름의 합을 C–C 단일결합에 대한 비율로 적용합니다. 기본 결합 길이 30 pt에서 C–C는 30, C=C는 26.8, C≡C는 24, C–O는 27.6, C=O는 24.8 pt입니다. 실제 분자에 대한 양자화학적 최적화가 아니라, 결합 길이 차이를 반영한 2D 작도 기준입니다.

단일·이중·삼중결합 도구, 산소 원소 버튼, 원자 단축키로 결합을 추가할 때 같은 기준을 사용합니다. 끝 원자의 원소나 결합 차수를 바꾸면 연결 방향과 현재 배율을 유지하면서 길이를 조정합니다. Alt를 누르고 드래그하면 자유 길이 작도를 유지합니다.

기존 파일의 좌표는 열 때 이 기준으로 다시 배치하지 않습니다. 기존 구조에 반영하려면 **구조 정리 → 2D 결합·고리 재정리**를 사용하세요. 원본 형태 유지 모드는 기존 비율을 보존합니다. 고리의 균일한 형태, 기존 벤젠 크기, 금속·배위·보호 구조의 작도 기준은 유지합니다. C/N/O 이외의 원소는 기존 기본 길이를 사용합니다.

참고: Pyykkö·Atsumi의 [단일결합 공유 반지름](https://doi.org/10.1002/chem.200800987), [이중결합 공유 반지름](https://doi.org/10.1002/chem.200901472), Pyykkö·Riedel·Patzschke의 [삼중결합 공유 반지름](https://doi.org/10.1002/chem.200401299).

## 도구 모음

상단 두 줄의 시작점, 버튼 폭·높이, 열 간격을 통일했습니다. 아래 줄에는 템플릿 분류와 회전·반전 도구가 있습니다.

오른쪽 위의 **도구 / 레이어**, **구조 정리**, **템플릿 / 보관**은 유지합니다. 그 아래에서 작업 탭을 선택하세요.

- **메커니즘**: 반응 추가·단계 표·단계 추가·설정, 자동 정렬·촉매 순환, 구조 삽입, 예제.
- **그래프**: 그래프 추가·데이터 표·경로 추가·경로 스타일, 축 설정·단계 화살표·출판용 정돈, 구조 삽입, 예제.

캔버스에 독립된 구조를 추가하는 파일 삽입은 두 탭 아래의 공통 버튼에 있습니다. 탭 전환 자체는 문서를 변경하지 않습니다.

## 오비탈

왼쪽 맨 아래 그리기 줄의 **오비탈**을 선택합니다. 옆의 **설정**에서 s(원형), p(두 로브), d(네 로브), 혼성(큰 로브와 작은 로브)을 선택하고 위상 표시를 지정합니다. 흑백 채움/윤곽, 전체 윤곽선, 청색/적색의 세 가지 표시를 지원합니다. 혼성 모양은 한 개 혼성 오비탈의 로브를 표현합니다.

- **클릭**: 기본 크기로 배치합니다.
- **드래그**: 시작점을 중심으로 방향과 로브 크기를 정합니다. 원자 위에서 시작하면 원자 중심에 맞춥니다.
- **Shift+드래그**: 방향을 30도 단위로 맞춥니다.
- **Space로 선택**: 로브 전체를 함께 이동합니다. 회전·반전, Ctrl+K 크기 조정도 지원합니다.
- **더블클릭**: 모양·위상·크기·각도를 편집합니다.
- **Ctrl+Z / Ctrl+Shift+Z**: 추가·속성 변경을 한 번에 되돌리거나 다시 적용합니다.

오비탈은 그룹으로 묶인 벡터 곡선·원으로 저장합니다. .ydraw, CDXML, SVG, Office 복사에서도 로브 모양과 위상 표현을 유지하며, 새 이미지 파일이나 외부 글꼴 설치가 필요하지 않습니다.


## 촉매 순환 배치와 화살표 삭제

구조들을 선택하고 **촉매 순환**을 적용하면 구조·이름·에너지·화살표 설명의 공간을 확보해 원형으로 배치합니다. 글이 길어지거나 글자 크기를 바꾸면 필요한 간격을 다시 계산합니다. 기존 문서는 반응 블록을 선택해 촉매 순환을 다시 적용하면 새 배치로 정리됩니다.

**메커니즘 설정 → 전체 글자 크기**에서 이름, 에너지, 설명과 가운데 `Cycle`의 크기를 함께 변경합니다. `0`은 자동 크기입니다.

선택 도구에서 순환 고리의 **화살표 선이나 화살촉을 클릭**하면 해당 화살표가 강조됩니다. **Delete / Backspace**를 누르면 선택한 화살표만 삭제하고 구조와 주석은 유지합니다. 지우개 도구로 화살표를 클릭해도 삭제할 수 있습니다. **Ctrl+Z**로 되돌리거나 **메커니즘 설정 → 삭제한 순환 화살표 → 모두 복원**으로 전체 고리를 복원합니다. 삭제 상태와 글자 크기는 `.ydraw`와 CDXML에 저장됩니다.


## 단계 이름 첨자와 줄바꿈

단계 표의 이름 셀(분기형 메커니즘의 이름 / TS 설명 열 포함)에서 글자를 선택한 뒤 **Ctrl+=** 또는 **x₂** 버튼으로 아래첨자, **Ctrl+Shift+=** 또는 **x²** 버튼으로 위첨자를 적용합니다. 같은 단축키를 다시 누르면 일반 입력으로 돌아갑니다. 편집 중에는 `Fe^{III}`, `H_{2}` 형태로 보이며 캔버스에는 첨자로 표시됩니다.

표의 셀, 캔버스 텍스트, 텍스트 속성 창에서 **Alt+Enter**를 누르면 현재 위치에서 줄을 바꿉니다. 표에서는 **Enter**로 다음 행, **Tab**으로 다음 셀로 이동합니다. 캔버스 텍스트에서는 **Enter**로 편집을 마치며 기존 **Shift+Enter** 줄바꿈도 사용할 수 있습니다.


## 메커니즘 기본 구조 크기

메커니즘의 구조 삽입은 일반 구조 크기의 140%로 표시하며 원자 글자와 결합선도 함께 키웁니다. 자동 설명·이름·에너지 글자 크기는 문서의 기본 글자 크기(기본 14 pt)를 사용합니다. 구조 영역 크기에 따라 설명 글자가 계속 커지지 않으며, 화살표와 구조 사이에는 최소 14 pt 여백을 둡니다.

기존 반응 블록은 선택 후 **크기·간격 자동 정렬**을 적용하면 새 자동 글자 비율에 맞춰 간격을 다시 계산합니다. **메커니즘 설정 → 전체 글자 크기**가 `0`일 때 자동값을 사용하며 직접 지정한 크기는 유지합니다. 기존 구조를 추가로 확대하려면 구조 삽입 영역을 선택하고 **Ctrl+K**로 크기를 조정할 수 있습니다.


## 그래프 굵기와 다중도 표기

그래프를 선택한 뒤 **그래프·축 설정 → 그래프 두께**에서 **굵게 (기존)** 또는 **얇게 (선·축·글자)**를 선택합니다. 얇게는 x·y축, 눈금선, 경로선·파선, 평평한 에너지 준위선, 범례 선을 기존 두께의 절반으로 표시하고, 축 제목·눈금·상태 이름·에너지 값·범례의 굵은 글씨를 해제합니다. 경로별로 지정한 선 굵기를 기준으로 적용하므로 굵게로 돌아가면 기존 두께를 복원합니다. 선택은 `.ydraw`와 CDXML에 저장되며 SVG와 Office 복사에도 반영됩니다.

다중도 `S = 0`, `S=1`, `S = 2` 등의 표기는 두 굵기 모드에서 모두 이탤릭으로 표시합니다.


얇은 그래프 글자는 벡터 윤곽에 안티앨리어싱을 적용해 표시합니다. 소수 배율 확대·축소와 세로 에너지 축에서도 같은 방식으로 그리며, Office 복사의 글자도 벡터 윤곽을 유지합니다.


**그래프·축 설정 → 평평한 준위선만 굵게 → 예**를 선택하면 얇은 모드에서도 각 상태의 평평한 에너지 준위선은 기존 굵은 두께로 표시합니다. 축·글자·파선과 연결선은 얇은 상태를 유지합니다. 같은 에너지를 잇는 수평 연결선에는 적용하지 않습니다. 이 옵션은 `에너지 준위 (점선 연결)` 및 `평평한 준위와 직선` 그래프에서 적용되며 저장·내보내기에도 반영됩니다.


## 새 그래프 · 에너지 갭 · TS

오른쪽 **그래프 → 새 그래프** 또는 **삽입 → 에너지 그래프**를 누르면 먼저 형태 선택 창이 열립니다. **부드러운 곡선 / 직선 / 준위·점선 연결 / 준위·실선 연결 / 독립 에너지 준위**를 아이콘 카드로 고르고 **ΔE·에너지 / ΔG·자유 에너지**를 선택한 뒤 **만들기**를 누릅니다. 취소하면 문서에 아무것도 추가하지 않습니다. 다음 에너지 표에서 상태와 수치를 편집합니다. 기본 그래프에는 에너지 갭이나 `//` 생략이 없습니다. 독립 준위 카드는 스핀 다중도 등의 비교에 사용합니다.

기본 선은 얇게, 글자는 보통 굵기로 표시하며 곡선·직선 그래프의 상태 이름은 해당 점 아래에 놓습니다. 구조는 기존 **그림 영역 → 붙여넣기 / 파일로 채움**으로 추가합니다. **제목·축**에서 형태·두께·글자·단위와 ΔE/ΔG 표기를 나중에도 바꿀 수 있습니다. 표기를 바꾸면 자동 갭 문구도 함께 바뀌며, 직접 작성한 갭 문구와 에너지 수치는 유지됩니다. 단위를 바꾸며 수치까지 변환할 때는 해당 설정을 별도로 선택합니다.

**갭 추가**는 필요할 때 사용합니다. 출발 상태·도착 상태·경로를 선택하고 적용한 뒤 **캔버스의 원하는 위치를 클릭**하면 그 자리에 갭을 만듭니다. 클릭한 가로 위치에 양방향 화살표가 놓이며, 세로 위치에 문구가 놓입니다. 화살표 양끝은 선택한 두 상태의 실제 에너지를 따릅니다. 배치 전 **Esc**로 취소할 수 있고, 배치 후 문구를 드래그하면 화살표 가로 위치와 문구 세로 위치를 조정합니다. **Ctrl+Z**로 배치·이동을 각각 되돌립니다. 같은 도착 상태에 갭을 다시 추가하면 그 상태의 기존 갭을 교체합니다.

갭 문구를 비워 두면 `ΔE = 값` 또는 `ΔG = 값`으로 자동 계산합니다. TS는 선택한 표기에 이중 대거 `‡`를 추가하며, 음수 차이는 부호를 유지합니다. 에너지·단위 수치를 바꾸면 자동 문구도 갱신됩니다. 직접 문구를 입력할 수도 있습니다.

그래프를 선택하고 **TS·위치**(메뉴: **배치 → 그래프 TS·이름 위치**)에서 상태별 설정을 편집합니다. 변경은 미리보기로 표시되며 취소하면 복원됩니다.

- **이름·위치**: 이름을 x축, 곡선 위·아래에 놓거나 숨깁니다. 기준 경로와 X·Y 이동량(pt)을 상태별로 지정합니다. 여러 줄 이름과 첨자를 지원하며 축을 숨겨도 이름은 독립적으로 표시됩니다.
- **TS·구간 생략**: TS 표기를 사용하면 위·아래에 넣은 구조를 각각 `[ ]‡`로 감쌉니다. 구조를 이동하거나 크기를 바꾸면 괄호도 따라갑니다. 아직 구조가 없으면 `[TS1]‡`처럼 이름에 표시합니다. **다음 상태까지의 구간 //**는 연결선에 실제 틈과 두 슬래시를 만듭니다. 위치는 구간의 5~95%로 조정하고 원래 에너지 값은 유지합니다.
- **에너지 갭**: 기존 갭의 출발 상태·경로·문구·위치를 수정하거나 **표시 안 함**으로 제거합니다. **제목·축 → 기본 → 에너지 표기**에서 ΔE/ΔG를 선택합니다.

**제목·축 → 축 표시**에서 x축·y축을 각각 표시하거나 숨깁니다. 설정은 `.ydraw`와 CDXML에 저장되고 SVG·Office 복사에도 같은 벡터 도형으로 반영됩니다. 에너지 표에서 출발 상태를 제거하면 연결된 갭도 사라지며, 연속성이 달라진 구간의 생략 표시는 해제됩니다.


## 기존 그래프의 스타일 변경

그래프를 선택하고 오른쪽 **그래프 → 스타일 변경** 또는 **배치 → 그래프 스타일 변경**을 엽니다. 현재 형태가 선택된 상태에서 곡선·직선·준위형의 다섯 그림 카드를 고르면 캔버스에 즉시 미리보기가 표시됩니다. **적용**으로 확정하고 **취소 / Esc**로 원래 형태를 복원합니다. 적용 후 **Ctrl+Z**로 되돌릴 수 있습니다.

이 명령은 그래프 형태만 바꿉니다. 에너지 수치·상태 이름·경로·색·굵기·ΔE/ΔG·축 설정·삽입 구조·TS·갭·구간 생략 설정은 유지합니다. 독립 준위에서는 연결선과 스핀 교차점을 그리지 않으며, 연결되는 형태로 다시 바꾸면 기존 설정대로 표시합니다.


## 그래프 그림에서 TS로 지정

그래프의 **상태 이름·에너지 점·해당 상태에 삽입한 구조를 우클릭 → TS로 지정**하면 연결된 구조에 대괄호와 이중 대거 `[ ]‡`가 바로 표시됩니다. 위·아래 구조가 있으면 각각 감싸며, 구조를 옮기거나 크기를 바꾸면 괄호도 따라갑니다. 아직 구조가 없으면 상태 이름을 `[TS1]‡`처럼 표시합니다.

같은 위치에서 우클릭해 **TS 지정 해제**하면 구조를 유지하고 표시만 숨깁니다. **TS·위치 → TS·구간 생략 → 상태 유형 → TS**에서도 지정할 수 있으며, Ctrl+Z로 되돌립니다. 이름을 더블클릭하거나 에너지 표에서 `TS`, `TS1`, `TS_{2}`처럼 이름을 바꾸면 자동으로 TS로 지정하고, TS 이름을 `Int1` 같은 이름으로 바꾸면 일반 상태로 돌아갑니다. 수동으로 TS를 해제한 뒤 같은 이름을 그대로 두고 에너지만 고치는 경우에는 해제 상태를 유지합니다.


## 그래프 전체 획 굵기와 축 길이

그래프를 선택하고 **+ / -**를 누르면 축·곡선·눈금·이름·에너지 값·TS 괄호·갭·범례와 그래프에 삽입한 벡터 구조의 획 굵기를 함께 조절합니다. 키패드 +/−도 사용하며 Shift는 필요하지 않습니다. 글자 크기·화학 구조 크기·에너지 수치는 바꾸지 않고, 선택 그래프 밖의 다른 구조에는 적용하지 않습니다. Ctrl+플러스/마이너스는 기존처럼 화면 확대·축소입니다.

선택한 그래프의 **가로축 오른쪽 끝 / 세로축 위쪽 끝의 작은 네모(□)**를 드래그하면 해당 축 길이만 바뀝니다. 축 교차점은 고정되며 이름·에너지 점·반응 범위·갭·TS 괄호·삽입 구조가 새 길이에 맞춰 따라갑니다. 구조는 찌그러뜨리지 않고 위치만 이동합니다. 드래그 중 **Esc**로 취소하고, 적용 후 **Ctrl+Z**로 관련 위치까지 한 번에 되돌립니다.

정확한 수치를 쓰려면 **그래프 → 축 길이·굵기** 또는 **배치 → 그래프 축 길이·굵기**에서 가로·세로 길이(pt)를 각각 입력합니다. 화살표 끝까지의 실제 축 길이이며, 전체 획 굵기를 25~400%(100% 기본)로 지정할 수도 있습니다. 미리보기와 취소를 지원하고 설정은 `.ydraw`·CDXML에 저장됩니다. 화면·PNG·Office 복사와 SVG에도 조절된 획 굵기를 반영합니다.


## 구간 생략 스케일과 봉우리 높이

**TS·위치 → TS·구간 생략**에서 **다음 상태까지의 구간 //**를 켜고 **생략 스케일**을 지정합니다. 50%는 두 상태 사이의 에너지 구간을 세로로 압축하고, 200%는 펼칩니다. 100%는 원래 비율이며 1~400%를 입력할 수 있습니다. **생략 에너지 구간의 기준 경로**에서 두 에너지의 기준이 될 경로를 고릅니다. 슬래시 위치는 별도로 5~95%에서 조절합니다.

봉우리·연결선·눈금·갭의 화살표가 같은 에너지 축을 따르며, 실제 에너지 값과 ΔE/ΔG 계산은 유지합니다. 슬래시 옆에는 적용 비율을, y축에는 스케일이 달라지는 구간의 생략 표시를 표시합니다. 여러 생략 구간이 겹치면 겹친 부분에는 더 작은 비율을 한 번 적용합니다. 스케일을 100%로 바꾸거나 //를 끄면 원래 높이 비율로 돌아갑니다. 연결선이 없는 독립 준위에서는 적용하지 않습니다.

## 반응 이름의 화살표 크기와 굵기

**그래프 → 반응 이름·화살표**에서 시작·끝(%)으로 양쪽 화살표 범위를 지정합니다. 화살촉은 이름을 제외한 실제 화살표 길이에 맞춰 자동 조절합니다. **화살표 굵기**(0.1~8 pt)와 **화살촉 길이**(0.1~40 pt)를 각각 지정할 수 있고, 0은 자동입니다. 화살촉이 짧은 구간을 넘어가지 않도록 제한합니다. **화살표 자석 배치**로 반응 이름을 추가하거나 수정할 때도 두 값을 설정할 수 있습니다. 미리보기·취소·실행 취소 및 .ydraw/CDXML 저장을 지원합니다.


## 큰 음수 에너지 때문에 봉우리가 완만해 보일 때

예를 들어 `7.7 → 19.8 → −56.9`에서 **19.8 상태의 이름·점·삽입 구조를 우클릭 → 다음 상태까지 큰 에너지 구간 압축 (물결선)**을 선택합니다. 두 상태 사이에서 다른 에너지 준위가 없는 가장 큰 구간을 자동으로 찾아 10% 높이로 줄입니다. `7.7 → 19.8`의 국소 장벽은 그대로 살리고, −56.9까지 내려가는 큰 낙차의 가운데만 생략해 봉우리가 뚜렷해집니다. 에너지 수치와 갭 계산은 유지하며 Ctrl+Z로 되돌릴 수 있습니다.

**TS·위치 → TS·구간 생략**에서 표시를 **물결선**으로 고르고 비율을 조절할 수 있습니다. **압축 구간 하한·상한**을 둘 다 비우면 자동으로 선택하고, 예를 들어 `−50 / 0`을 입력하면 그 에너지 범위만 압축합니다. 봉우리 부근은 범위 밖에 두세요. 슬래시 // 표시에서도 직접 지정한 범위를 사용할 수 있습니다. 물결선에는 별도 퍼센트 문구를 그리지 않습니다.
