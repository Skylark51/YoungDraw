# 결합 길이와 도구 모음 개선

## 결합 길이

새로 그리는 C/N/O 결합은 결합 차수별 공유 반지름의 합을 C–C 단일결합에 대한 비율로 적용합니다. 기본 결합 길이 30 pt에서 C–C는 30, C=C는 26.8, C≡C는 24, C–O는 27.6, C=O는 24.8 pt입니다. 실제 분자에 대한 양자화학적 최적화가 아니라, 결합 길이 차이를 반영한 2D 작도 기준입니다.

단일·이중·삼중결합 도구, 산소 원소 버튼, 원자 단축키로 결합을 추가할 때 같은 기준을 사용합니다. 끝 원자의 원소나 결합 차수를 바꾸면 연결 방향과 현재 배율을 유지하면서 길이를 조정합니다. Alt를 누르고 드래그하면 자유 길이 작도를 유지합니다.

기존 파일의 좌표는 열 때 이 기준으로 다시 배치하지 않습니다. 기존 구조에 반영하려면 **구조 정리 → 2D 결합·고리 재정리**를 사용하세요. 원본 형태 유지 모드는 기존 비율을 보존합니다. 고리의 균일한 형태, 기존 벤젠 크기, 금속·배위·보호 구조의 작도 기준은 유지합니다. C/N/O 이외의 원소는 기존 기본 길이를 사용합니다.

참고: Pyykkö·Atsumi의 [단일결합 공유 반지름](https://doi.org/10.1002/chem.200800987), [이중결합 공유 반지름](https://doi.org/10.1002/chem.200901472), Pyykkö·Riedel·Patzschke의 [삼중결합 공유 반지름](https://doi.org/10.1002/chem.200401299).

## 도구 모음

상단 두 줄의 시작점, 버튼 폭·높이, 열 간격을 통일했습니다. 아래 줄에는 템플릿 분류와 회전·반전 도구가 있습니다.

오른쪽 위의 **도구 / 레이어**, **구조 정리**, **템플릿 / 보관**은 유지합니다. 그 아래에서 작업 탭을 선택하세요.

- **메커니즘**: 반응 추가·단계 표·단계 추가·설정, 자동 정렬·촉매 순환, 구조 삽입, 예제.
- **그래프**: 그래프 추가·데이터 표·경로 추가·경로 스타일, 축 설정·단계 화살표·출판용 정돈, 구조 삽입, 예제.

캔버스에 독립된 구조를 추가하는 파일 삽입은 두 탭 아래의 공통 버튼에 있습니다. 탭 전환 자체는 문서를 변경하지 않습니다.

## 오비탈

왼쪽 맨 아래 그리기 줄의 **오비탈**을 선택합니다. 옆의 **설정**에서 s(원형), p(두 로브), d(네 로브), 혼성(큰 로브와 작은 로브)을 선택하고 위상 표시를 지정합니다. 흑백 채움/윤곽, 전체 윤곽선, 청색/적색의 세 가지 표시를 지원합니다. 혼성 모양은 한 개 혼성 오비탈의 로브를 표현합니다.

- **클릭**: 기본 크기로 배치합니다.
- **드래그**: 시작점을 중심으로 방향과 로브 크기를 정합니다. 원자 위에서 시작하면 원자 중심에 맞춥니다.
- **Shift+드래그**: 방향을 30도 단위로 맞춥니다.
- **Space로 선택**: 로브 전체를 함께 이동합니다. 회전·반전, Ctrl+K 크기 조정도 지원합니다.
- **더블클릭**: 모양·위상·크기·각도를 편집합니다.
- **Ctrl+Z / Ctrl+Shift+Z**: 추가·속성 변경을 한 번에 되돌리거나 다시 적용합니다.

오비탈은 그룹으로 묶인 벡터 곡선·원으로 저장합니다. .ydraw, CDXML, SVG, Office 복사에서도 로브 모양과 위상 표현을 유지하며, 새 이미지 파일이나 외부 글꼴 설치가 필요하지 않습니다.


## 촉매 순환 배치와 화살표 삭제

구조들을 선택하고 **촉매 순환**을 적용하면 구조·이름·에너지·화살표 설명의 공간을 확보해 원형으로 배치합니다. 글이 길어지거나 글자 크기를 바꾸면 필요한 간격을 다시 계산합니다. 기존 문서는 반응 블록을 선택해 촉매 순환을 다시 적용하면 새 배치로 정리됩니다.

**메커니즘 설정 → 전체 글자 크기**에서 이름, 에너지, 설명과 가운데 `Cycle`의 크기를 함께 변경합니다. `0`은 자동 크기입니다.

선택 도구에서 순환 고리의 **화살표 선이나 화살촉을 클릭**하면 해당 화살표가 강조됩니다. **Delete / Backspace**를 누르면 선택한 화살표만 삭제하고 구조와 주석은 유지합니다. 지우개 도구로 화살표를 클릭해도 삭제할 수 있습니다. **Ctrl+Z**로 되돌리거나 **메커니즘 설정 → 삭제한 순환 화살표 → 모두 복원**으로 전체 고리를 복원합니다. 삭제 상태와 글자 크기는 `.ydraw`와 CDXML에 저장됩니다.


## 단계 이름 첨자와 줄바꿈

단계 표의 이름 셀(분기형 메커니즘의 이름 / TS 설명 열 포함)에서 글자를 선택한 뒤 **Ctrl+=** 또는 **x₂** 버튼으로 아래첨자, **Ctrl+Shift+=** 또는 **x²** 버튼으로 위첨자를 적용합니다. 같은 단축키를 다시 누르면 일반 입력으로 돌아갑니다. 편집 중에는 `Fe^{III}`, `H_{2}` 형태로 보이며 캔버스에는 첨자로 표시됩니다.

표의 셀, 캔버스 텍스트, 텍스트 속성 창에서 **Alt+Enter**를 누르면 현재 위치에서 줄을 바꿉니다. 표에서는 **Enter**로 다음 행, **Tab**으로 다음 셀로 이동합니다. 캔버스 텍스트에서는 **Enter**로 편집을 마치며 기존 **Shift+Enter** 줄바꿈도 사용할 수 있습니다.


## 메커니즘 기본 구조 크기

메커니즘의 구조 삽입은 일반 구조 크기의 140%로 표시하며 원자 글자와 결합선도 함께 키웁니다. 자동 설명·이름·에너지 글자 크기는 문서의 기본 글자 크기(기본 14 pt)를 사용합니다. 구조 영역 크기에 따라 설명 글자가 계속 커지지 않으며, 화살표와 구조 사이에는 최소 14 pt 여백을 둡니다.

기존 반응 블록은 선택 후 **크기·간격 자동 정렬**을 적용하면 새 자동 글자 비율에 맞춰 간격을 다시 계산합니다. **메커니즘 설정 → 전체 글자 크기**가 `0`일 때 자동값을 사용하며 직접 지정한 크기는 유지합니다. 기존 구조를 추가로 확대하려면 구조 삽입 영역을 선택하고 **Ctrl+K**로 크기를 조정할 수 있습니다.


## 그래프 굵기와 다중도 표기

그래프를 선택한 뒤 **그래프·축 설정 → 그래프 두께**에서 **굵게 (기존)** 또는 **얇게 (선·축·글자)**를 선택합니다. 얇게는 x·y축, 눈금선, 경로선·파선, 평평한 에너지 준위선, 범례 선을 기존 두께의 절반으로 표시하고, 축 제목·눈금·상태 이름·에너지 값·범례의 굵은 글씨를 해제합니다. 경로별로 지정한 선 굵기를 기준으로 적용하므로 굵게로 돌아가면 기존 두께를 복원합니다. 선택은 `.ydraw`와 CDXML에 저장되며 SVG와 Office 복사에도 반영됩니다.

다중도 `S = 0`, `S=1`, `S = 2` 등의 표기는 두 굵기 모드에서 모두 이탤릭으로 표시합니다.


얇은 그래프 글자는 벡터 윤곽에 안티앨리어싱을 적용해 표시합니다. 소수 배율 확대·축소와 세로 에너지 축에서도 같은 방식으로 그리며, Office 복사의 글자도 벡터 윤곽을 유지합니다.


**그래프·축 설정 → 평평한 준위선만 굵게 → 예**를 선택하면 얇은 모드에서도 각 상태의 평평한 에너지 준위선은 기존 굵은 두께로 표시합니다. 축·글자·파선과 연결선은 얇은 상태를 유지합니다. 같은 에너지를 잇는 수평 연결선에는 적용하지 않습니다. 이 옵션은 `에너지 준위 (점선 연결)` 및 `평평한 준위와 직선` 그래프에서 적용되며 저장·내보내기에도 반영됩니다.
