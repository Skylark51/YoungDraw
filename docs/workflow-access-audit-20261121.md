# YoungDraw 접근 편의·응답성·깊이 표시 점검 (2026-11-21)

## 원칙과 범위

기존 기능, 메뉴, 단축키, 문서 형식과 과학 데이터의 의미를 유지한다. 기능을 삭제하거나 계산·편집 방식을 단순화하지 않고, 실제 기능 진입과 조작 중 불필요한 대기·화면 재시작·중복 계산만 개선한다. 깊이 표시의 잘못된 앞뒤는 별도 정확성 문제로 수정한다.

## 보존 확인

- 기존 152개와 BQCN·MeSiP₂ 14개, 총 166개 템플릿을 유지한다.
- 리간드 템플릿의 원자·결합 연결과 S,S / R,R 입체화학은 보존한다. 사용자 지시에 따라 원본 XYZ를 그대로 투영하는 대신 고리·치환기·라벨이 읽히는 논문용 도식으로 배치했다. 원본 추출 XYZ와 출처는 별도 보관한다.
- 기존 메뉴와 단축키를 제거하지 않는다. Ctrl+Shift+F 명령 검색을 그대로 사용한다.
- 프로젝트·문서 탭·저장·복구·클립보드·일반 분자 편집·구조 정리·메커니즘·에너지 그래프·GIF·Office·테마는 기존 전체 CTest로 회귀 검사한다.
- 색의 정확성과 적층 순서는 캔버스, PNG, SVG, Office 장면과 일반 CDXML 경로를 검사한다.

다중 획 보강은 별도 회귀로 검사한다. 앞쪽 이중·삼중·방향족·물결 결합 × 뒤쪽 단일·이중·삼중 결합 × 5°·15°·45°·90°의 48개 조합에서 실제 모든 선분의 간격을 확인한다. 얕은 각도에서는 앞 선분의 유한한 길이 밖에 있는 뒤쪽 끝을 보존하며, 앞쪽의 각 획은 검정색과 획 수를 유지한다.

## 성능 측정의 해석

같은 글꼴·크기·스타일의 동일 문구를 1,200회 측정하는 로컬 비교에서 원래 GDI 호출은 약 20.3 ms, 캐시 사용은 약 0.10 ms였다. 이 수치는 텍스트 측정 단계만의 비교이며 앱 전체가 같은 비율로 빨라진다는 의미는 아니다. 실제 측정은 build/ligand-spatial-release/workflow-performance.json에 기록된다.

## 논문용 도식

최종 배치는 [실제 레퍼런스 기준](ligand-publication-reference.md)을 따른다. Co–Si 원논문 Scheme 1과 BQCN 연구 원고의 실제 스킴을 확인하여 가로 배위 축, 위아래 고리, 오른쪽 반응 공간과 일반 굵기의 검정 글자·가는 선을 반영했다.

## 최종 로컬 검증

build.ps1로 빌드한 동일 실행 파일의 격리 데스크톱 CTest 30/30 최종 재검사가 통과했다(42.84초). 입체 10개 템플릿의 720개 시점에서 2,132개 교차를 검사했다. 수동 회색·검정색 지정, 작은 휠 입력 누적, 2열 키보드 이동과 검색 포커스 전환도 실제 메시지로 검사했다. 중간 전체 검사에서 GIF 종료 구간 예외와 PNG 클립보드 확인·종료 구간의 대기가 각각 한 번 있었다. GIF 격리 재실행 7회, PNG 동일 바이너리 집중 검사(0.28초), 최종 전체 검사에서 모두 통과했으며, 재현 근거 없는 앱 변경은 추가하지 않았다.

Desktop과 별도로 클립보드까지 새 Window Station에 격리하는 방식을 조사했으나, 현재 권한에서 이름 지정 생성은 오류 5, 자동 이름 생성은 기존 객체 오류 183으로 중단됐다. 기존 station 재사용·권한 상승·사용자 Desktop 대체 실행은 하지 않았다. 사용자 클립보드 쓰기 전에 중단됐고, 추가 강화 초안은 ignored build에만 보관했다. 배포하는 scripts/test-isolated.ps1은 원래 전용 Desktop 방식 그대로다. Windows의 클립보드 소유 범위는 [Window Stations](https://learn.microsoft.com/en-us/windows/win32/winstation/window-stations)를 참고한다.

## 자동 검증과 자료

workflow_access_audit는 메뉴 연결·검색 노출·갤러리 조작·기존 템플릿·교차 깊이·텍스트 측정 정확성을 검사한다. 모든 로컬 테스트는 scripts/test-isolated.ps1을 통해 테스트 전용 Windows 데스크톱에서 실행하며 사용자 화면으로 전환하지 않는다.

상세 결과: build/ligand-spatial-release/workflow-depth-audit.csv, workflow-performance.json, Testing/Temporary/LastTest.log. 과거 실패 검사도 빌드 디렉터리에 보관하고 배포 소스에는 포함하지 않는다.

CDXML 그래픽 적층의 기준은 [CrossingBonds](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/Bond_CrossingBonds.htm)와 [ZOrder](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/properties/ZOrder.htm) 명세이다.
