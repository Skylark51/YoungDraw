# 2026년 11월 메커니즘·에너지 그래프 검증

## 작업 전 상태

C++17/Win32 구현에 이미 분기·합류·촉매 순환, 단계 삽입·삭제, 원본 위치 유지,
네이티브/CDXML 스마트 메타데이터 및 Office OLE 왕복 저장이 있다.
전체 재작성 대신 실제 가져오기 및 배치 오류를 보완했다.

## 수정

- CDXML의 꼬리 쪽 화살촉만 지정된 직선·곡선은 제어점을 역순으로 바꿔 방향과
  편집 가능한 화살촉을 보존한다. 곡선 속성의 두 가지 대소문자 표기도 처리한다.
- 실제 ChemDraw 파일에서 반복된 `objecttag` ID 때문에 도면 전체를 거부하던
  문제를 수정했다. 이 메타데이터는 원문에 보존하며 캔버스 객체로 만들지 않는다.
  도형 자체의 중복 ID 검증은 유지한다. 내보내기에서도 메타데이터 ID를 도형 ID로
  오인하여 덮어쓰지 않는다.
- 긴 에너지 그래프 범례는 글자 외에 선 견본과 간격까지 포함해 가로 폭을 계산한다.

`objecttag`의 역할은 [ChemDraw SDK의 Object Tag 설명](https://iupac.github.io/IUPAC-FAIRSpec/cdx_sdk/ObjectTag.htm)을 참고했다.
반복 ID 허용은 실제 로컬 ChemDraw 자료에 근거한 호환성 처리다.

## 재현

`build.ps1`은 기본으로 Release 빌드와 창을 만들지 않는 CTest 9개를 실행한다.
전체 UI 테스트는 로컬에서 반복 실행하지 않는다. `november_complex_graphs`는
9개 상태, 3~7개 경로, 수동 축 범위, 결측 에너지, 양방향 분기, 출판용 정돈의
5종 그래프를 SVG/CDXML/네이티브 파일로 출력하고 편집 원본 왕복 일치를 검사한다.

실제 자료 검증은 빌드 폴더에서 다음과 같이 실행한다.

```powershell
./november_validation.exe '<ChemDraw CDXML 자료 폴더>'
```

원본은 읽기만 한다. 서식 변경·저장·재열기, 원자 좌표 보존, 메커니즘 변환,
분기 추가·저장·제거를 검사한다. 변환 불가 자료는 별도로 기록하고,
변환 가능 자료 20개 또는 자료 폴더 끝까지 검사한다. 연구 원본과 임시 출력은 커밋하지 않는다.

## 한계와 후속 검증

- 네이티브/CDXML 왕복 일치는 YoungDraw 편집 데이터의 보존을 확인한다.
  ChemDraw에서 직접 다시 열어 모든 서식을 대조한 검증과는 다르다.
- Office CTest는 OLE 데이터 저장·복원 회귀 검사다. 실제 PowerPoint에서
  붙여넣기·슬라이드 저장·재열기·더블클릭 편집은 별도의 통합 검증이 필요하다.
- SVG 검토는 자동 출력과 화면 렌더링을 확인하며 학술지 게재 적합성을 보장하지 않는다.
- 일부 가져오기 경고 및 변환 불가 자료는 계속 추적해야 한다. 12월에는
  지원되지 않는 ChemDraw 도형·다중 페이지·양끝 화살촉과 실제 Office 흐름을 우선 검증한다.

## 실행 결과

- 전체 CTest: 18/18 통과. 이후 사용자 요청에 따라 UI 테스트 반복 실행을 중단했다.
- 창을 만들지 않는 CTest: 9/9 통과.
- 실제 ChemDraw 연구 파일 26개: 가져오기·선 굵기 수정·CDXML 및 네이티브 왕복 검사 통과.
  19개는 메커니즘 변환 후 분기 추가·저장·제거 및 원자 위치 보존을 통과했다.
  7개는 구조 수 또는 화살표 연결 조건 때문에 변환 불가로 별도 기록했다.
- 다중 경로 그래프 5종 SVG/CDXML/네이티브 출력 검사 통과.
  SVG 1종은 숨겨진 headless 렌더링으로 화면 배치도 확인했다.
- 일부 원본은 미지원 도형 경고가 남아 있다. 따라서 이번 결과만으로
  모든 ChemDraw 메커니즘 및 실제 PowerPoint 재편집이 완성됐다고 판단하지 않는다.
