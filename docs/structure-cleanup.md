# 구조 정리: RDKit 코드 활용 1차 개선

## 목표와 적용 위치

YoungDraw의 기존 2D 배치가 만든 겹침 때문에 분자 전체가 원래 좌표로 되돌아가는 경우, 단일 결합의 한쪽 가지를 뒤집어 정리 결과를 구제합니다. 실행은 기존 **구조 정리 (Ctrl+Shift+K)**에서 이루어집니다. RDKit 라이브러리나 Python 설치 없이 기존 단일 실행 파일로 동작합니다.

`layout.cpp`의 기존 배치·고리 가독성 보정 뒤에 `layout_refine.cpp`의 탐색을 수행하고, 마지막에는 기존 충돌 검사로 결과를 검증합니다. 기준 템플릿을 적용한 구조, 원본 좌표 유지 모드, 이번 작업에서 좌표가 바뀌지 않은 분자는 추가 탐색에서 제외합니다.

## RDKit에서 가져온 부분과 YoungDraw의 변경

- 원본: RDKit `Code/GraphMol/Depictor/EmbeddedFrag.cpp`, 커밋 `5dd33d41483491afa99106643e78071c7ddcb379`.
- 참고 함수: `flipAboutBond`, `findCollisions`, `totalDensity`, `tryResolvingCollisionWithBondFlip`, `removeCollisionsBondAndSpiroFlip`.
- 원본 링크: https://github.com/rdkit/rdkit/blob/5dd33d41483491afa99106643e78071c7ddcb379/Code/GraphMol/Depictor/EmbeddedFrag.cpp
- 결합을 끊었을 때 한쪽에 속하는 원자들을 찾고, 결합선을 축으로 그쪽 좌표를 반사하는 탐색을 YoungDraw의 `Document`/원자 ID에 맞게 재작성했습니다. RDKit의 분자 모델·링커 의존성은 가져오지 않았습니다.
- 충돌 개수와 원자 사이 역제곱 거리 밀도로 후보를 비교하는 방식을 적용했습니다. YoungDraw에서는 **원본에 없던 충돌 → 전체 충돌 → 밀도** 순으로 비교합니다.
- 원자 중심 거리만 쓰지 않고 기존 `makeScene`의 라벨 경계, 글자와 결합의 겹침, 서로 독립인 결합선의 교차를 검사합니다. 라벨 문구·색상·위아래첨자·수동 오프셋은 변경하지 않습니다.
- 원자 수·결합 종류·연결 관계·원자 ID와 모든 결합 길이를 유지합니다. 고리가 있는 쪽 전체가 반사될 수 있지만 고리 내부 결합을 축으로 반사하지 않으므로 고리 모양은 유지됩니다. 분자 중심도 유지하여 반복 정리의 위치 이동을 방지합니다.
- 탐색은 결정적이며 분자당 최대 8회 개선/96회 후보 평가로 제한합니다. 100원자를 넘는 분자는 기존 정리 경로를 사용합니다.
- 이전 그림과 새 후보의 결합 길이·각도가 이미 같고 충돌도 줄지 않는다면 이전 그림의 가지 방향을 유지합니다. 이는 동등한 배치 사이를 오가며 반복 정리 결과가 달라지는 현상을 막습니다.

## 1차 적용 범위

일반 유기 분자의 유연한 사슬과 가지를 대상으로 합니다. 보호 원자·잠긴 항목, 금속, 쐐기/해시/배위 결합, 특수 결합 서식이 있는 분자는 뒤집지 않습니다. 이중·삼중 결합에 직접 붙은 단일 결합도 축에서 제외합니다. 입체 투영 보존·금속 착물 배치·기준 템플릿·벤젠 및 연결 결합 길이는 기존 정책을 따릅니다.

현재 단계에서는 새로운 고리 배치 알고리즘, 원자가 검증, 반응 원자 매핑, 이미지 인식을 추가하지 않습니다. 해결되지 않은 새 충돌은 기존 방식대로 해당 분자를 복원합니다.

## 출처와 배포

RDKit의 BSD 3-Clause 라이선스와 저작권 고지는 `resources/rdkit-license.txt`에 보관합니다. 단일 실행 파일에도 전체 고지를 포함하며 **보기 → 오픈소스 라이선스**에서 확인할 수 있습니다. `src/third_party_notices.h`의 고지는 이 텍스트를 유지해야 합니다.

검증은 `layout_refinement`와 기존 전체 CTest 회귀 테스트로 수행합니다. 접힌 사슬의 충돌 감소, 결합 길이·분자 위치·라벨 보존, 보호 구조·입체 결합·금속·고리의 보존을 확인합니다.
