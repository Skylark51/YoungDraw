# ΔE·ΔG 축 제목 표시

에너지 표기 선택이 그래프의 `energySymbol`·`yLabel`은 바꾸면서 편집 중인 축 제목 입력란은 이전 값으로 남기는 문제를 수정했다. Y축 관리, 통합 축 관리와 기존 그래프·축 설정에서 선택한 표기가 제목 입력란·미리보기·SVG에 함께 반영된다. 제목에 ΔE·ΔG를 직접 입력하는 경우에도 표기 정보를 맞춘다.

구형 문서와 일부 기본 그래프에는 `energySymbol` 없이 `yLabel`에만 ΔE·ΔG가 있다. 상단 제목은 이런 문서를 `E`로 그렸고, 에너지 갭은 ΔE 제목도 기본 ΔG로 해석했다. 기존 제목의 Δ 표기를 사용하도록 수정했다. 일반 Energy/E 제목과 사용자 지정 제목, 에너지 수치·단위 변환 기능은 유지한다.

추가한 회귀 검사로 수정 전 코드의 기존 ΔE 에너지 갭 불일치를 재현했다(`build/axes-unified/delta-before-failure.log`). 최종 검사는 기존 문서의 세로·상단 ΔE/ΔG 제목, 저장·재열기, 실제 선택 조작 후 입력란과 미리보기 및 SVG 일치, 취소·실행 취소를 포함한다. 로컬 전체 CTest 33/33 및 실행 파일의 20개 내보내기 검사가 통과했다.
